## 关键重构决策

### 用户端

1. **继承而非推翻**：保留暗色 `#08090d`、暖象牙文字、琥珀强调、mono 元信息、胶片颗粒与光晕；把原先散落的圆角（8/12/16/24）收敛为 6/10/14/20/28 五档，间距统一到 8pt。
2. **导航重做**：92px 图标 rail + 单一 72px 顶栏；rail 有滑动指示器、按压反馈，移动端降级为底部五项。
3. **媒体详情统一**：
   - 旧问题：图片有 3 套详情、视频有 4 套布局；不同原始尺寸导致容器和文字列跳动。
   - 新规则：一个 Drawer，两列 `minmax(0,1fr) / 392px`；舞台固定 `clamp(320px, 58vh, 660px)`，媒体 `object-fit: contain`；信息列独立滚动；引用图、参数、Prompt、操作位置恒定。
   - 图片与视频共用标题、Prompt、事实表、来源、操作区；视频只替换播放器与时长/结算字段。
   - 移动端单列，舞台在上、信息在下。
4. **动效克制**：路由/卡片入场 420–520ms，悬停位移 2–3px，按钮按压 `scale(.985)`，抽屉 420ms spring-out；全部尊重 `prefers-reduced-motion`。
5. **创作台**：参数列改为“模型 → 提示词 → 参考图 → 尺寸 → 质量 → 数量”固定顺序，估价与提交固定在底部；画布区使用阶段轨道而非零散状态文案。

### 管理端

1. **推翻旧视觉**：暖灰纸面（`#f2f1ec`）、白色面板、墨色文字、单一墨蓝强调（`#2e4a7d`）；侧栏为 248px 浅色导航；移除 11px 正文与 Fraunces 装饰。
2. **字号纪律**：
   - 页面标题 30px / 区块 15px / 正文 15px / 表格 14px / 标签 13px / 辅助 12.5px / 机器字段 11px mono。
   - 行高 1.55；数字统一 `tabular-nums`。
3. **表单重构**：
   - 废除自由双栏流式布局；改为**单列字段账本**：每个字段独占一行，标签在上、控件全宽、帮助文本在下。
   - 仅允许“同高短字段”成对（如最小/最大、优先级/权重），且使用同一 grid 行，保证基线。
   - 长表单拆 section（编号 + 标题 + 一句说明）；保存栏 sticky，显示未保存数与校验结果。
4. **列表统一**：
   - 一套 `filter band + data table + pager`；
   - 行高 56px，表头 sticky，数字右对齐 mono，状态用语义 badge；
   - 操作列使用 32px 按钮与 36px 图标按钮，不再用细小文字链；
   - 分页器统一页码、总数、每页条数与跳页。
5. **多级详情统一进抽屉**：
   - 720px 常规 / 1020px 复杂；
   - 头部固定身份与状态，body 可分页签，底部固定操作；
   - 覆盖用户、图片任务、视频任务、接入账号、真实模型、路由、候选、价格、订单、套餐、渠道实例、兑换码核销、审计、管理员。
6. **实体映射**：
   - 用户：头像 + 名称 + 邮箱；点击打开摘要弹窗（余额、状态、最近活跃、本月生成），可进入完整用户抽屉。
   - 路由/模型：名称 + code + 账号；缺失映射回退 ID 并标灰。
   - 枚举：任务状态、结算状态、支付状态、审核状态全部中文标签 + 语义色（如 `partial → 部分成功`、`finalized → 已结算`）。
   - ID 仅以 mono 小字用于复制/排障，不作为主信息。
