1. 统一画布空白区域交互状态
   - 在 `CanvasEditorPage.tsx` 增加页面级的“取消当前画布瞬时状态”逻辑，覆盖参考素材选择、连接草稿、快捷创建菜单、分组配置、节点/边选择，并清理未完成的框选、平移、缩放/长按临时状态。
   - 复用该逻辑到 Escape 处理，保证空白点击与 Escape 行为一致；生成控制台通过取消节点选择自然卸载，已展开的控制台也随之关闭。
   - 为空白 pointer 交互增加点击/拖动阈值：按下时记录起点，只有超过小阈值才开始/提交画布平移；未超过阈值的 pointerup 执行取消逻辑。拖动画布期间不执行取消，触摸长按和双指缩放继续保持现有行为。
   - 防止双击快捷创建菜单在拖动后误打开，并保留节点、工具栏和控制台区域的事件隔离。

2. 修复鼠标指针与画布工具入口
   - 将普通画布空白区域的默认指针改为与普通组件交互一致的默认指针，不再显示加号/crosshair；仅在 Space/实际平移状态显示 grab/grabbing，连接端口和连接线继续使用各自的专用指针。
   - 从画布底部 dock 移除右侧资产入口按钮及对应图标/契约要求；保留控制台内针对生成参考图的本地上传、资产库选择和画布参考流程，不影响生成控制台功能。

3. 修复图生视频图片格式能力匹配
   - 在 `internal/domain/video` 增加视频输入格式归一化和别名匹配：同时兼容 `image/png` 与 `png`、`image/jpeg` 与 `jpg/jpeg`、`image/webp` 与 `webp` 等 MIME/扩展名表示，并保持不支持格式仍返回字段级能力错误。
   - 在视频能力匹配处使用该专用比较逻辑，不改变媒体类型、分辨率等其他比较规则；资产到视频请求的 MIME 读取保持明确且统一。
   - 增加领域和服务回归测试，覆盖 `first_frame` 与 `reference_image` 的 PNG/JPEG MIME 对短格式能力配置、无效格式拒绝，以及 estimate/create 共用校验的一致性。

4. 增加小屏底部工具栏可移动手柄并处理重叠
   - 在 `canvas-dock` 中增加独立的拖动手柄，保留 `data-canvas-no-zoom`，仅手柄响应拖动；按钮点击不触发工具栏拖动或画布平移。
   - 复用工作台已有的 pointer capture、pointerId 校验、拖动阈值、pointercancel/lost capture 清理和拖后 click 抑制模式，将 dock 的水平位移保存在页面 UI 状态，不写入画布文档、撤销栈或远端保存。
   - 对位移做 viewport 边界限制；窗口尺寸/方向变化后重新 clamp。桌面端默认居中，小屏允许水平拖动，并给缩放条预留独立区域，加入安全区间距，避免与右下缩放工具栏重叠。
   - 更新 coarse pointer 下的手柄和 dock 按钮点击尺寸、光标与触摸行为。
