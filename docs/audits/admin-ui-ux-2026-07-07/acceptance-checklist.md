# 管理端 UI/UX 整改验收清单

- 桌面端路由截图覆盖：运营总览、系统健康、用户、用户分组、审核队列、订单、套餐、支付配置、接入账号、路由模型、价格策略、调用记录、审计日志、管理员、通用配置、安全配置、存储配置。
- 移动端截图覆盖：运营总览、用户、存储配置。
- 所有受保护页面不得出现 `CURRENT VIEW`、`ADMIN ROLE`、`QUEUE ALERTS`、`PENDING REVIEW` 旧全局状态条文案。
- `390px` 宽移动端不得出现页面级横向溢出，侧栏应通过抽屉进入。
- 导航分组只使用中文分组名，系统设置拆分为通用配置、安全配置、存储配置。
- 用户表格行内常驻操作收敛为详情和更多，禁用/删除需要确认。
- 支付渠道实例新增/编辑使用右侧抽屉，并展示基础信息、金额限制、结构化字段、密钥字段、高级 JSON 步骤。
- 通用配置只展示低风险类目，认证安全、生成限制、内容审核和支付配置不得混入通用配置页。
- 路由模型展示可用状态，并在空状态或创建后引导继续配置候选模型。
- 存储配置独立为一级页面，列表和详情同时可见，默认写入实例完整可辨认。

可选自动化：

```bash
ADMIN_BASE_URL=http://127.0.0.1:8088/admin/ node scripts/visual/admin-ui-snapshot.mjs
```
