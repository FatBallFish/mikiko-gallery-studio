# 录音纪要（修正版） — 图片生成类新项目

## 一、项目概述

* 项目类型：图片生成类产品
* 项目定位：介于 API 中转服务和独立图像生成模型服务之间

  * 依赖底层 API（如 GPT、Gemini 等）
  * 在底层 API 基础上封装应用能力：图床管理、提示词优化、单独计费计算等
* 仓库状态：空仓库，从零开始实现

---

## 二、功能模块

### 1. 用户模块

* **注册与登录**

  * 邮箱注册/登录，验证码验证
  * 预留账号密码登录、微信/谷歌登录等第三方登录方式
  * 修改密码、忘记密码流程
* **个人信息**

  * 昵称、签名、头像
  * 可扩展配置项
* **偏好设置**

  * 系统主题颜色
  * 默认消费方式或习惯（初期预留）

* **额度信息**

  * 订阅套餐情况
  * 当前剩余额度
  * 历史消耗额度

* **充值兑换**

  * 积分额度充值
  * 订阅套餐购买
  * 兑换码兑换

* **密钥管理**

  * AK/SK密钥生成、删除、重置、启用/禁用
  * 密钥额度配置
  * 密钥分组配置
  * 密钥过期时间配置
  * 密钥速率配置

---

### 2. 核心功能 — 图片生成

* **文字生成图片**（文字 → 图）
* **参数配置**

  * 图片质量（1K / 2K / 4K 可单独配置消耗积分）
  * 图片数量
  * 分辨率 / 比例
  * **兼容性处理**：

    * 不同底层图像框架可能参数不一致
    * 技术方案需设计统一接口，中转参数或独立页面展示
* **请求模式**

  * 同步等待返回
  * 异步轮询查询结果
* **积分计费**

  * 用户充值积分（积分兑人民币汇率可配置）
  * 单次生图消耗积分可根据图片质量或套餐单独配置
  * 积分封装底层模型调用的 token 或次数计费
* **用户可选操作**

  * 可选择特定“抽象模型”或套餐

    * 平台内部封装模型等级：基础 / Plus / Pro
    * 选择模型 → 内部随机调度对应底层模型（如国内千问模型、Banana 模型等）
  * 分组模型消耗与订阅绑定：不同分组消耗倍率或额度可独立设置
  * 超级管理员后台可配置模型分组和消耗策略

---

### 3. 模型对接模块

* 功能类似中转站，参考 NewAPI / Sopto API
* 支持多个底层图像模型
* **核心功能**

  * 优先级路由
  * AB分流路由
  * 异常报错降级策略
  * 不同模型调用方式兼容处理（如 GPT-IMAGE-2 与 OpenRouter 等差异）
* 后台管理可配置模型分组及调度逻辑

---

### 4. 超级管理员后台

* **功能**

  * 积分管理与汇率设置
  * 兑换码管理：生成、核销、失效、批量导出
  * 单次生图积分消耗管理（可按分组/质量/套餐设置）
  * 模型接入管理
  * 优先级及降级策略配置
  * 分组模型抽象及调度配置
  * 用户管理：创建用户、禁用用户、重置密码、积分增减、设置并发、设置RPM等
  * 历史调用记录查看与成本核算
  * 系统稳定性监控大盘
  * 平台运营监控大盘

* **用户体系**

  * 独立于客户前端的管理员用户体系
* **支付接口**

  * 支持支付宝、微信支付及其他支付方式
* **管理要求**

  * 可视化配置和管理，便于运营调整

---

## 三、技术与交付要求

* **交付形式**

  * Docker 容器化部署
  * 包含：

    1. 后端服务
    2. 客户端前端
    3. 管理后台前端
* **开发规范**

  * 优先复用已有代码（如参考项目代码）
  * 避免重复造轮子
  * 按照 PRD → 技术方案 → 实现的流程进行
* **兼容性要求**

  * 技术方案需兼顾不同底层图像生成框架参数差异
  * 用户界面和后台需支持分组模型与参数配置的灵活调整
