# 故障排查

## 先检查凭据

- `MIKIKO_API_KEY` 必须是一次显示的 SK（`sk-`），不是 AK（`ak-`）。
- 确认账号和密钥启用，未过期，scope 覆盖当前操作。
- MCP 使用 OAuth 令牌；浏览器会话不能代替它。

## 再检查模型与额度

1. 重新发现模型及能力。
2. 使用完整请求预检。
3. 检查余额、密钥配额和 RPM。
4. 检查任务与资产详情，区分生成和保存阶段。

## 保留排查信息

记录请求 ID、任务 ID、模型和失败阶段。不要记录完整令牌或上传签名 URL。

接入地址为 `https://mikiko.studio`；原生 REST 前缀 `/api/open/v1`，OpenAI 前缀 `/v1`，MCP 为 `/mcp`。OAuth 代理与错误诊断见 [MCP 指南](mcp.md)。
