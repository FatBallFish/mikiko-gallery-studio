# Developer capability inventory

The approved scope is [the unified API and MCP design](../plans/2026-10-24-unified-api-mcp-design.md). The canonical wire contract is `api/openapi/openapi.yaml`; `web/docs/public/openapi` is generated by `web/docs/scripts/sync-openapi.mjs`. Product features are not automatically developer API capabilities.

| Capability | Existing product implementation | Unified developer surface |
| --- | --- | --- |
| Identity and balance | Browser profile, balance buckets and ledger | `me`, `me/balance`; no developer password login |
| Image generation | Capability discovery, references, estimates, persistent tasks, image results | Image models, complete-request preflight, task creation/list/detail/events |
| Video generation | Video capability/rate-card discovery, estimates, persistent tasks and cancellation | Video models, complete-request preflight, task creation/list/detail/events/cancel |
| Media management | Image/video assets, processing, access links, grouping and project transfers | Asset list/detail/update/delete/access; renewable temporary access URLs |
| Uploads | Multipart sessions, checksums, status, signing, completion and abort | Upload init/status/part URL/bytes/complete/abort |
| Projects | Default project, create/rename, optimistic version checks and resource transfer on deletion | Project CRUD; owned resources only |
| Asset groups | Existing display `group_name` workflows | Persistent project-scoped groups; single asset assignment; deleting a group clears grouping only |
| OpenAI compatibility | `/v1/models`, image generations and edits | Same routes with Bearer API Key; synchronous results and documented platform lifecycle SSE extension |
| API keys | Hashed secrets, status, expiry, RPM and total/day quota | Bearer only; explicit operation scopes; existing image access does not imply new destructive/video scopes |
| MCP | New adapter in this scope | Shared application operations through standard Streamable HTTP and browser OAuth |
| OAuth | Existing browser login/OIDC | New authorization code + PKCE S256, consent, opaque access/refresh tokens, rotation and connected-app revocation |

## Separate trust boundaries

| Surface | Preserved paths / implementation | Developer API relationship |
| --- | --- | --- |
| Public image gallery | `/api/open/image/v1/gallery/images`, `/{image_id}`, `/{image_id}/access` | Retains existing public/detail permission rules, not a signed user endpoint |
| Public video gallery | `/api/public/v1/videos`, `/{asset_id}`, `/{asset_id}/video`, `/{asset_id}/poster` | Existing public publication boundary |
| Payment callback | `/api/open/image/v1/payments/webhooks/{channel}` | Provider-specific verification; no developer Bearer replacement |
| Video provider callback | `/api/open/video/v1/provider-callbacks/{provider_code}/{account_public_id}` | Provider-specific verification; no developer Bearer replacement |
| Browser | `/api/agent/…` | Existing login/OIDC, account, ledger, subscriptions, cashier, publishing, history, canvas and prompt optimization |
| Administration | `/api/ops/admin/…` | Existing configuration, user/key groups, storage, models/routing/prices, reviews, orders, metrics and cluster management |
| Cluster enrollment | `/api/open/cluster/v1/challenges`, `/join` | Deployment trust mechanism; excluded from developer reference |

## Implementation and compatibility limits

The operation catalogue in `internal/service/openplatform/catalogue.go` and adapter routes are the implementation sources for REST and MCP schemas. Check the deployed contract before depending on a parameter or operation. Canvas execution, prompt optimization, cashier, publishing/reviews, batch export and task history management are existing product features outside the approved unified developer operation catalogue.

Native tasks are the persistent async mechanism. A dropped event connection is not a task outcome. Do not assume event replay, `Last-Event-ID` recovery, permanent event retention, or provider cancellation guarantees without an explicit implemented contract. Platform queue/running/persisting events are not partial images. Partial-image events require real upstream support; unsupported parameters must be rejected, never silently approximated.

Preflight does not charge. Quotes bind identity, the normalized request and current capability/price versions and expire. Creation revalidates and reserves costs. Monetary point quantities are decimal strings with five fractional digits. Do not assume a quote is an authorization to bypass account state, key quotas, ownership or capability checks.

MCP targets protocol `2026-07-28` using the pinned official Go SDK `v1.7.0`, with prior versions limited to that SDK's supported negotiation. Read `initialize` and `tools/list`; tool schemas and annotations describe actual available operations. MCP has no password-login tool. OAuth tokens are for the canonical `/mcp` resource, not browser sessions or arbitrary downstream resources.
