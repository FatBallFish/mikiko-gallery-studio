# 视频厂商原生计费重构需求

> 状态：用户已确认，进入开发
> 目标版本：v0.0.25

## 目标

将当前难以配置的视频组合成本、视频价格策略和参数价格规则，重构为贴合 Seedance 与 MiniMax H3 官方计费口径的结构化销售费率，并支持一个视频路由同时绑定多个不同厂商真实模型。

## 已确认需求

1. Seedance 按真实模型、输出分辨率、输入是否包含视频配置 CNY/百万 Token 销售单价。
2. Seedance 使用官方 Token 估算公式；输入包含视频时应用官方最低 Token 规则。
3. MiniMax H3 按分辨率配置输出视频 CNY/秒和输入视频 CNY/秒。
4. MiniMax H3 支持输入音频免费、输入图片前 5 张免费、超出部分按张收费。
5. 管理员填写的是已包含成本、利润和风险的销售单价，不再配置支付费率、净收入、目标毛利、成本缓冲或 reserve markup。
6. 平台复用系统唯一的 `billing_pricing.cny_per_point` 将 CNY 换算为积分。
7. 混合路由对本次请求的所有可用候选模型分别报价，取最高销售价并在生成前锁价。
8. Provider 实际用量仅用于审计，不改变用户锁定积分。
9. 路由不再维护逐组合最终积分，只维护最低任务积分和积分取整步长。
10. 多结果任务继续按单结果锁价乘请求数量预留，按成功数量最终结算，失败结果释放积分。
11. 允许破坏性清理旧视频价格配置并要求管理员重新配置、重新启用视频路由；旧 Provider 成本规则只为升级前在途任务的 attempt 兼容读取而暂存，不进入新配置和 v2 报价。
12. 历史任务报价快照、积分流水和结算结果必须保留；执行中的旧任务仍能按旧快照结算。

## 验收

1. 后台真实模型费率表单只展示厂商需要的关键费率字段。
2. Seedance、MiniMax 官方示例计算结果通过单元测试。
3. Seedance 与 MiniMax 混合路由能完成参数映射、候选筛选、最高价和固定报价。
4. 费率、路由配置、能力或积分汇率变化会使未提交报价失效，不影响已创建任务。
5. 旧视频策略、参数价格和组合成本不再进入新任务运行时或后台操作流程；legacy 在途任务读取原成本规则属于兼容例外。
6. 全量验证、代码审查、API smoke、PR 合并和 v0.0.25 发布 Action 全部成功。
