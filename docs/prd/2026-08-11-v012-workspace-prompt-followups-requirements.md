# v0.0.12 创作与首页体验跟进需求

日期：2026-08-11
状态：已实现，待发布
实现基线：`v0.0.12`（`1fdfb5b`）

## 1. 模型分组下拉框

1. 创作页模型分组不得继续使用浏览器原生 `select`。
2. 下拉框的视觉、浮层和选项反馈应与提示词变量、资产候选菜单保持一致。
3. 每个选项展示三部分：
   - Title：模型分组名称；
   - SubTitle：模型分组描述，为空时不渲染且不占高度；
   - Subject：右侧展示 `◈XX`，其中 XX 为该分组最低积分。
4. 控件支持键盘打开、上下移动、Enter 选择、Escape 关闭、点击外部关闭，并暴露正确的无障碍状态。

## 2. 图片编辑来源名称布局

1. 缩略图只承载图片预览和移除操作，资产名称移动到图片下方单独一行展示。
2. 名称过长时允许省略，但完整名称必须可通过 `title` 或等价方式查看。
3. 点击名称行的编辑图标打开弹窗重命名；弹窗展示完整名称，支持保存、取消、Enter 提交和 Escape 关闭。
4. 沿用现有重命名 API；成功后同步更新当前草稿中的同名资源 Tag。

## 3. 提示词 Tag 与自动补全

1. 资产和变量 Tag 视觉上只显示 key，不显示 `{{@`、`{{$` 和 `}}`；底层标准模板文本保持不变。
2. 每个 Tag 右上角提供可访问的关闭按钮。关闭只删除当前点击的这一处 Tag，不删除其他同名 Tag。
3. 手动输入普通 `{{}}` 不触发资产或变量菜单。
4. 用户输入新的未转义 `$` 或 `@` 时可触发一次候选菜单。
5. 对当前触发位置按 Escape 或点击菜单外空白处后，保留已输入文本，并记住该触发已取消；只要该触发文本未被删除或重建，就不得重复弹出。
6. 用户删除后重新输入新的 `$` 或 `@` 时，允许再次触发。
7. 工具栏主动打开菜单不受上述单次取消规则影响。

## 4. 首页公开 Prompt 复制

1. 首页公开作品卡片和匿名列表接口继续只展示 `prompt_excerpt`，不得把完整 Prompt 放入列表响应。
2. 首页打开详情时，在已有登录会话下请求公开图片详情，使用详情中的完整 `prompt` 更新弹窗。
3. 复制按钮复制完整详情中的 Prompt，而不是视觉截断文本或 `prompt_excerpt`。
4. 详情请求失败时展示明确错误，不得把摘要伪装成完整复制结果。

## 5. 验收标准

1. 桌面和移动端不存在文本重叠、溢出或不可点击控件。
2. 模型下拉、Prompt 候选菜单和重命名弹窗均可只用键盘完成主要操作。
3. 同名 Tag 重复两次时，关闭其中一个仅删除对应 occurrence。
4. 取消 `$`/`@` 菜单后继续输入不会反复弹出；重新输入新的触发字符会再次弹出。
5. 长 Prompt 在首页视觉上仍可截断展示，但复制结果必须与详情接口完整 Prompt 完全一致。
