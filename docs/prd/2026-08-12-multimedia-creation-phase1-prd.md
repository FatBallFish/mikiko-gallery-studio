# 多媒体创作平台一期产品需求文档

日期：2026-08-12
状态：需求输入已确认，待技术评审与实施
目标基线：v0.0.12 及当前工作树 `codex/v012-workspace-prompt-followups`
产品结构：快捷创作 + 创意画布 + 统一资产
上游范围：Seedance 2.5、Seedance 2.0、MiniMax H3
相关预研：`docs/tech/2026-08-11-multimedia-creation-platform-research.md`

## 1. 文档目的

当前平台已经具备较完整的 AI 图片生成、项目、资产、积分和模型路由能力，但创作链路仍以单次图片生成为中心。用户无法直接生成视频，图片与未来视频/音频没有统一资产入口，也缺少把提示词、素材和多次生成关系组织起来的可视化工作区。

本期目标是在不引入专业视频剪辑器的前提下，把平台升级为可持续扩展的多媒体创作平台，首先完成：

1. 常规参数的视频生成体验；
2. 视频生成路由、任务和计费链路；
3. 支持生图、生视频的可视化画布；
4. 本地上传及图片、视频、音频统一资产管理。

本文从产品角度定义页面、用户流程、业务规则、状态、异常处理和验收口径。具体表结构、接口和 Worker 架构由后续技术设计确定。

## 2. 已确认决策

### 2.1 产品信息架构

采用以下结构：

- **创作**：面向低门槛、单次快速生成，内部切换“图片生成 / 视频生成”。
- **创意画布**：独立一级入口，面向需要组织素材、提示词和连续生成步骤的用户。
- **资产**：统一管理图片、视频和音频，包括平台生成和本地上传来源。

不采用以下方案：

| 方案 | 不采用原因 |
| --- | --- |
| 将“生图”“生视频”拆成两个一级菜单 | 导航变长，创作历史和参数体验割裂，后续每增加一种媒体都会继续膨胀 |
| 用画布完全替代现有创作页 | 简单生成也必须理解节点和连接，学习成本过高，破坏现有用户习惯 |
| 一期直接建设专业视频剪辑台 | 与本期“生成和资产底座”目标不匹配，时间线、转码和导出范围过大 |

### 2.2 画布产品名称

用户侧名称统一使用 **“创意画布”**，副标题为“可视化编排图片与视频生成”。

“无限画布”只用于描述底层交互能力，不作为菜单和页面主标题。相较“节点工作台”，“创意画布”更少技术术语；相较“灵感画布”，它更能表达用于实际创作生产。

### 2.3 授权前提

项目所有者已确认通过线下与 Nova Image Studio 作者沟通取得商业授权，本期允许复用其无限画布实现。该授权没有在当前项目仓库中形成授权文件、许可证变更或其他代码层证明；本文只记录项目所有者的业务确认，不虚构仓库内凭证。Nova 自身第三方依赖仍需按各自许可证履行义务。

### 2.4 一期边界

一期支持常规图片和视频生成，不建设自动运行的复杂工作流，也不建设视频时间线编辑器。

画布中的连接用于组织输入关系。用户必须在具体生成节点上主动点击生成，每次扣费前都能看到预计积分；连接变化不会自动触发下游任务。

### 2.5 交付约束

本产品由一人公司独立负责产品、设计、开发、测试、运维和上线，没有多人角色分工、固定里程碑或预设上线窗口。开发按技术依赖拆包推进，每个包完成实现、自动化测试和回归后继续；全量功能通过验证即可上线。该约束不能作为省略计费一致性、数据迁移、安全、可访问性或故障恢复的理由。

## 3. 背景与现状问题

### 3.1 平台能力缺口

1. 创作页只有图片生成，无法覆盖视频创作者的基础需求。
2. 当前图片生成结果、参考素材和项目能力可以复用，但数据和交互仍以图片为中心。
3. 现有资产页无法上传本地素材，也无法统一管理视频和音频。
4. 单次表单适合快速生成，但多轮创作后提示词、参考图和结果之间的关系难以追踪。
5. 视频单次成本远高于图片，如果缺少明确预估、冻结和结算展示，用户容易产生费用争议。
6. 视频任务耗时长且上游为异步任务，若仍只显示笼统“处理中”，用户无法判断是排队、生成还是结果转存。

### 3.2 产品机会

1. 通过统一图片和视频的快捷入口，降低已有图片用户尝试视频的成本。
2. 通过创意画布承接多轮生成和素材关系，提高资产复用与连续创作效率。
3. 通过统一资产管理，让本地素材、平台结果和未来导演台共享同一底座。
4. 通过路由模型屏蔽 Seedance 和 MiniMax 差异，使用户按效果、速度和价格选择模型分组，而不是理解厂商接口。

## 4. 产品目标与成功指标

### 4.1 产品目标

1. 新用户无需阅读厂商文档即可完成一次视频生成。
2. 图片用户可以在原“创作”路径内自然切换到视频，不丢失项目上下文。
3. 用户能在提交前理解预计费用，在完成后核对实际扣费。
4. 用户能通过创意画布组织提示词、图片输入和生成结果，并继续进行图片或视频生成。
5. 用户能上传、查找、预览、下载和复用图片、视频、音频资产。
6. 生成结果、上传资产、画布和项目之间具备一致且可恢复的关系。

### 4.2 首期观测指标

指标用于上线后判断产品有效性，不作为单次研发测试的替代：

| 指标 | 定义 | 首期建议目标 |
| --- | --- | ---: |
| 视频首单完成率 | 打开视频生成并开始填写的用户中，成功完成至少一次视频生成的比例 | >= 45% |
| 视频任务成功率 | 扣除用户主动取消后的成功任务数 / 已提交任务数 | >= 90%，按模型分组分别观察 |
| 费用争议率 | 因预估与实际扣费不清晰产生的客服/退款请求占成功视频任务比例 | < 0.5% |
| 结果转存成功率 | 上游成功任务中，在 URL 失效前成功转存平台存储的比例 | >= 99.9% |
| 画布激活率 | 创建画布的用户中完成至少一次节点生成的比例 | >= 35% |
| 画布复访率 | 创建画布后 7 天内再次打开同一画布的用户比例 | 作为基线观测 |
| 本地上传成功率 | 完成初始化的上传中最终形成可用资产的比例 | >= 98% |
| 派生资源成功率 | 可处理媒体中成功生成必要缩略图、海报、预览或波形的比例 | >= 99% |

目标值需要结合灰度数据调整。不得通过隐藏失败、自动重试重复扣费或降低合法性校验来提高指标。

## 5. 用户角色与核心任务

### 5.1 轻量创作者

希望输入提示词、选择少量参数后快速获得图片或视频，不愿理解节点和厂商差异。

核心任务：

- 文生视频；
- 用一张已有图片生成视频；
- 查看等待状态、费用和结果；
- 下载结果或继续复用。

### 5.2 视觉创作者

需要反复调整提示词、参考图和模型，保留多个方向并比较结果。

核心任务：

- 在创意画布中组织素材和提示词；
- 从一张图继续生成图片或视频；
- 保留不同迭代分支；
- 从资产库反复调用素材。

### 5.3 素材管理者

拥有较多本地及平台素材，需要按项目和分组整理。

核心任务：

- 批量上传；
- 按媒体类型、来源、项目、分组查找；
- 预览、下载、移动、分组和删除；
- 把资产送入快捷创作或创意画布。

### 5.4 平台管理员

负责配置真实账号、模型能力、路由模型、销售价格和运行状态。

核心任务：

- 配置 Seedance、MiniMax 账号和真实视频模型；
- 配置用户可见的视频模型分组与常规参数；
- 配置视频销售价格和查看厂商成本；
- 排查失败任务、未完成转存和费用异常。

### 5.5 核心用户流程

快捷文生视频：

```text
进入创作并切换视频
  -> 确认项目和模型分组
  -> 选择文本生成视频
  -> 填写提示词和常规参数
  -> 核对预计积分
  -> 主动提交
  -> 查看排队 / 生成 / 保存状态
  -> 在任务或资产中预览、下载和复用
```

图片生成视频：

```text
从资产或图片结果点击“生成视频”
  -> 图片作为首帧进入视频草稿
  -> 选择模型分组并填写动作/镜头提示词
  -> 校验跟随素材比例和可用清晰度
  -> 核对费用并提交
  -> 结果自动进入当前项目资产
```

创意画布探索：

```text
在当前项目新建画布
  -> 添加提示词和图片素材
  -> 连接到图片或视频生成节点
  -> 在节点中核对参数与费用
  -> 手动执行当前节点
  -> 自动形成结果媒体节点
  -> 从结果继续创建新的生成分支
```

本地上传与复用：

```text
在资产页选择或拖入文件
  -> 直传并查看进度
  -> 平台校验和生成预览
  -> 设置项目/分组
  -> 在资产详情中继续创作或添加到画布
```

## 6. 术语

| 术语 | 定义 |
| --- | --- |
| 媒体类型 | 图片、视频或音频。 |
| 来源类型 | 平台生成、本地上传、画布生成或未来导出等资产来源。画布生成本质仍属于平台生成，可额外记录画布来源。 |
| 快捷创作 | 当前“创作”页面内基于表单的图片或视频生成方式。 |
| 创意画布 | 通过节点和连接组织提示词、素材和生成步骤的独立工作区。 |
| 画布 | 一份可保存、重命名和再次打开的创意画布文档。 |
| 生成节点 | 保存模型分组、提示词、参数和输入关系，并允许用户主动提交任务的节点。 |
| 媒体节点 | 展示图片或视频资产的节点，可以是输入，也可以是生成结果。 |
| 路由模型/模型分组 | 面向用户展示的抽象模型，底层可路由到多个真实账号和模型。用户侧继续使用“模型分组”。 |
| 预计积分 | 提交前依据销售价格规则计算并预留的积分。 |
| 实际积分 | 任务完成后依据计费规则和实际成功产物结算的积分。 |
| 原文件 | 用户上传或模型返回的未经平台预览转换的文件。 |
| 派生资源 | 缩略图、视频海报、低码率预览、音频波形等用于展示的媒体文件。 |

## 7. 范围与优先级

### 7.1 P0：上线阻塞能力

1. 创作页图片/视频模式切换。
2. 视频文生视频、单张首帧图生视频。
3. 模型分组、提示词、时长、比例、分辨率、音频开关等能力驱动参数。
4. 提交前费用预估、积分预留、成功结算、失败退款及用户账单明细。
5. Seedance 与 MiniMax H3 路由、任务状态、结果转存、失败分类。
6. 创意画布列表、创建、重命名、复制、删除和云端自动保存。
7. 提示词、图片、视频、音频、图片生成、视频生成和便签节点。
8. 画布内手动生图、生视频、查看状态和自动形成结果节点。
9. 图片、视频、音频本地上传和统一资产列表。
10. 图片缩略图、视频海报/悬停预览、音频波形/按需播放。
11. 统一资产的预览、下载、分组、项目转移、删除和批量操作。
12. 管理后台的视频模型能力、路由价格、任务和媒体策略配置。
13. 首尾帧图生视频，但只对明确支持的模型分组展示。
14. 一次生成 2-4 个视频方案，由平台拆成独立子任务并分别计费。
15. 画布小地图、节点搜索、自动整理选中节点。
16. 资产详情中的“添加到现有画布”。
17. 视频任务排队时的 best-effort 取消。
18. 画布模板：空白、图片探索、图片转视频。
19. 画布主动转移到用户拥有的其他项目；存在运行中生成任务时禁止转移。

以上均为本期 P0 范围，不再设置可延后的 P1 功能包。实施时仍应先完成计费、转存、统一资产和画布保存等可靠性底座，再接通依赖它们的交互功能。

## 8. 明确不在本期范围

1. 视频延长、视频编辑、局部重绘、2K regeneration、Context-IR 等厂商专属高级能力。
2. 视频作为生成参考输入、音频作为生成参考输入、多模态素材批量引用。
3. 专业时间线、多轨剪辑、转场、字幕、配音、音乐混合和最终成片导出。
4. 画布整图自动运行、定时运行、循环、条件分支、批量工作流和无人值守扣费。
5. 多人实时协作、评论、权限角色和共享项目。
6. 手机端完整画布编辑；平板横屏属于 P0 完整编辑范围。
7. 视频/音频公开广场；现有图片公开能力保持不变。
8. 用户自定义真实厂商、API Key 或任意 Provider 参数。
9. 本期为现有历史图片重新批量生成全部新规格缩略图；允许按需或后台渐进处理。

## 9. 产品信息架构与导航

### 9.1 桌面端一级导航

建议顺序：

```text
首页
创作
创意画布
资产
项目
积分
密钥
设置
```

“创意画布”使用画布/节点类图标，与“创作”的闪光图标和“资产”的网格图标区分。

### 9.2 移动端导航

当前移动端菜单项较多。新增入口后不得继续把所有菜单等宽塞入底部导航。

底部固定五项：

```text
首页 / 创作 / 画布 / 资产 / 我的
```

“我的”页或菜单承载项目、积分、密钥和设置。移动端菜单标题可缩写为“画布”，进入页面后的正式标题仍为“创意画布”。

### 9.3 项目上下文

1. 创作、创意画布和资产继续共享全站当前项目。
2. 新建画布必须属于当前项目；用户可在创建时改选项目。
3. 画布内生成的媒体默认进入画布所属项目，不受用户后来切换全站项目影响。
4. 打开其他项目的画布时，全站项目同步切换为该画布项目。
5. 从其他项目跨项目引用资产是允许的，资产本身不随引用迁移。
6. 从跨项目资产生成的新结果仍进入当前创作或画布所属项目。
7. 用户可主动把整份画布转移到自己拥有的其他项目；只修改画布归属和后续生成结果的目标项目，不迁移或复制画布引用的跨项目资产。
8. 画布存在运行中的图片或视频生成任务时禁止转移，任务完成或取消后方可操作，避免一次运行的结果项目语义发生变化。

## 10. 快捷创作总体需求

### 10.1 页面结构

“创作”页顶部增加媒体模式分段控件：

```text
[ 图片生成 ] [ 视频生成 ]
```

要求：

1. 现有用户第一次进入继续默认“图片生成”，避免版本升级后行为突变。
2. 用户主动切换后，在当前浏览器记住最近模式；从图片/视频资产的“继续创作”进入时由操作目标决定模式。
3. 图片生成保持当前能力和交互，不因视频接入降级。
4. 两种模式共享项目选择、模型分组样式、提示词模板、余额入口、当前任务/历史任务框架。
5. 不支持的参数不显示，不以禁用控件堆满页面。

### 10.2 视频生成页面布局

桌面端从上到下建议为：

1. 项目和模型分组；
2. 生成方式；
3. 首帧/尾帧素材；
4. 提示词编辑器；
5. 常规参数；
6. 费用预估与生成按钮；
7. 当前任务和历史任务。

移动端保持同一信息顺序，参数可使用底部抽屉，但费用和生成按钮必须始终在提交前可见，不允许按钮点击后才弹出未知费用。

## 11. 快捷视频生成详细需求

### 11.1 生成方式

P0 提供：

| 方式 | 用户名称 | 输入要求 | 说明 |
| --- | --- | --- | --- |
| `text_to_video` | 文本生成视频 | 提示词 | 从文字描述生成视频 |
| `image_to_video` | 图片生成视频 | 一张首帧图片 + 可选提示词 | 以图片作为视频起始画面 |

P0 对支持的模型提供“首尾帧生成视频”。当模型不支持时不得展示该选项。

切换生成方式时：

1. 保留提示词和两种方式都支持的参数。
2. 不兼容的素材先保留在当前草稿中，但提交前明确提示需移除或切回原方式。
3. 不得静默删除用户已选择的素材。

### 11.2 模型分组

沿用当前模型分组下拉样式：

- Title：分组名称；
- SubTitle：分组描述；
- Subject：右侧 `◈XX`，视频模型可展示默认时长、默认分辨率下的起步积分。

规则：

1. 只显示包含当前生成方式且存在启用候选和有效价格的模型分组。
2. 分组描述应突出适合场景，如“快速草稿”“高质量有声视频”，不暴露 Seedance/MiniMax 账号和渠道名称。
3. 切换模型后重新校验时长、比例、分辨率、音频和素材。
4. 原参数仍被支持时保持不变；不支持时自动选择该分组的明确默认值，并逐项展示变更提示。
5. 若无可用模型，显示“当前暂无可用视频模型”，同时保留已填提示词和素材草稿。

### 11.3 首帧与尾帧素材

素材来源：

1. 从资产选择；
2. 本地上传并使用；
3. 从当前任务或历史任务结果直接“用于视频生成”。

要求：

1. 本地上传成功后自动形成 `本地上传` 图片资产，再绑定到草稿，不创建仅属于表单的临时孤立文件。
2. 素材卡展示缩略图、名称、来源项目、替换和移除操作。
3. 选择首帧后，如果比例必须自适应，则隐藏比例选择并显示实际采用“跟随首帧”。
4. 素材尺寸、格式或大小不合规时，在选择后立即提示具体原因。
5. 跨项目引用允许，界面展示来源项目但不要求迁移。

### 11.4 提示词

1. 复用现有提示词编辑器、模板变量、资源 Tag、优化和全屏编辑能力。
2. 视频提示词优化使用视频场景专用内置 Prompt，保留 `{{$变量}}` 和 `{{@资源}}` 占位符。
3. 本期视频生成只把首帧/尾帧作为正式图片输入。提示词中的其他资源 Tag 若当前生成方式不支持，标红并阻止提交。
4. 展开变量值后再执行长度校验；长度上限由模型分组能力返回。
5. 任务必须保存用户原始模板提示词、变量快照和最终提交提示词。复用任务时变量值默认清空，沿用当前图片规则。

### 11.5 常规参数

| 参数 | 控件 | 默认规则 | 产品要求 |
| --- | --- | --- | --- |
| 时长 | 下拉选项 | 模型分组配置的默认值 | 只展示完整候选可支持的合法秒数；显示“5 秒”等用户语言 |
| 画面比例 | 图形化比例选项 | 分组默认；图生视频可为跟随素材 | 只展示能力支持项；`adaptive` 显示为“跟随素材/自动”而非接口枚举 |
| 清晰度 | 下拉或分段选项 | 分组默认 | 统一显示 480P、720P、768P、1080P、2K、4K；不假设不同厂商同名规格像素完全一致 |
| 生成音频 | 开关 | 默认由路由模型配置 | 只有完整候选都能满足时才展示；关闭时明确结果无模型生成音轨 |
| 输出格式 | 默认隐藏 | 路由模型默认 MP4 | 一期不让普通用户选择 MOV；若厂商返回 MOV，平台转存后按兼容策略处理 |
| 生成数量 | 数字步进器，P0 | 1 | 允许范围 1-4，具体上限由路由模型配置，每个结果单独生成和计费 |

要求：

1. 参数选项由平台能力矩阵返回，前端不得硬编码厂商全部枚举。
2. 路由模型的可选参数只能包含至少一个当前可用候选完整支持的组合。
3. 若不同参数组合导致候选变化，预计费用和可用状态必须立即重新计算。
4. 平台不得在提交后静默降低分辨率、缩短时长、关闭音频或移除素材。
5. 当前参数组合无候选时，生成按钮禁用，并明确指出冲突字段。

### 11.6 费用预估与提交

费用区域必须展示：

- 单个视频预计积分；
- 生成数量；
- 总预计积分；
- 预计积分是确定值还是上限预留；
- 用户当前可用积分；
- 影响费用的时长、清晰度和附加项摘要。

生成按钮建议展示：

```text
生成视频 · ◈120.00
```

若只能提供估算：

```text
生成视频 · 预留最高 ◈120.00
```

规则：

1. 参数或提示词变化后旧预估立即失效，生成按钮进入短暂“正在计算费用”状态。
2. 费用预估失败时不得按旧金额提交。
3. 余额不足时按钮变为“积分不足”，并提供充值入口，不清空草稿。
4. 提交成功后立即冻结预计积分，并在任务中展示“已预留”。
5. 防止双击重复提交；同一客户端请求号只能创建一组任务。
6. P0 多结果任务按子任务预留和结算，允许部分成功；父任务汇总总费用。

### 11.7 视频任务状态

用户侧状态统一为：

| 状态 | 展示文案 | 用户可执行操作 |
| --- | --- | --- |
| 校验中 | 正在检查参数与费用 | 无 |
| 排队中 | 已提交，等待模型处理 | 查看详情；厂商支持时申请取消 |
| 生成中 | 模型正在生成视频 | 查看详情 |
| 正在保存 | 视频已生成，正在保存到资产 | 查看详情，不允许重新提交 |
| 正在准备预览 | 正在生成预览文件 | 原文件已安全保存时可下载原件 |
| 已完成 | 视频已保存到资产 | 预览、下载、复用、添加到画布 |
| 部分完成 | 多结果任务中部分成功 | 查看每个结果、重试失败项 |
| 已失败 | 显示可行动的失败原因 | 修改参数后重试 |
| 已取消 | 任务已取消 | 复用参数重新生成 |

不得使用无法证实的连续百分比进度。若厂商没有真实进度，仅展示阶段、已等待时间和基于历史数据的宽泛等待提示。

### 11.8 失败与重试体验

错误按用户能否处理分组：

| 类型 | 示例 | 展示与操作 |
| --- | --- | --- |
| 参数错误 | 时长/比例不支持、素材过大 | 指向具体字段，保留草稿，要求修改后提交 |
| 余额错误 | 余额不足、冻结失败 | 展示所需和可用积分，提供充值入口 |
| 内容安全 | 提示词或素材未通过 | 使用平台安全文案，不泄露内部规则，允许修改 |
| 上游繁忙 | 限流、暂无可用候选 | 自动执行安全 fallback；最终失败时建议稍后重试 |
| 上游任务失败 | 模型明确失败 | 退款并展示可重试提示 |
| 结果保存失败 | 上游成功但平台转存失败 | 平台自动重试保存，不允许用户重新付费生成 |
| 预览处理失败 | 原文件已保存但海报/预览失败 | 允许下载原文件，平台重试派生处理 |

点击“重试”必须创建新的可审计任务。若原任务已经扣费，重试前重新估价并再次要求用户主动提交；不得后台静默生成第二个收费任务。

### 11.9 视频任务详情

详情至少展示：

- 任务状态与时间；
- 原始提示词模板和本次变量值；
- 首帧/尾帧；
- 模型分组、生成方式、时长、比例、清晰度、音频；
- 预计、预留、实际、退回积分；
- 成功视频结果；
- 失败原因和建议；
- “复用参数”“添加到画布”“下载”操作。

不得向用户展示真实账号密钥、厂商渠道名称、内部 fallback 次数或原始错误正文。管理员详情可查看经过脱敏的 attempt 信息。

## 12. 视频计费产品规则

### 12.1 基本原则

1. 用户按路由模型的销售价格付积分，不直接按随机命中的真实账号价格付费。
2. 提交前给出可理解的预计积分或最大预留积分。
3. 只有成功产物可以产生最终生成扣费；失败任务退回全部预留积分。
4. 上游成功但平台转存失败属于平台恢复任务，不得再次向用户收费。
5. 所有任务保存提交时的价格快照，后续管理员改价不影响历史任务。
6. 用户账本与管理员成本账本分离，但可按任务关联核对。

### 12.2 支持的计量项

底层价格规则至少预留：

| 计量项 | 本期用户场景 | 产品含义 |
| --- | --- | --- |
| 输出视频秒数 | P0 | 视频时长 × 对应清晰度单价 |
| 固定任务费 | 可配置 | 每个成功视频固定积分 |
| 参考图片 | P0 | 首帧、尾帧及未来更多参考图片的附加成本 |
| 输入视频秒数 | 本期不展示，底层预留 | 后续视频参考或编辑使用 |
| 参考音频秒数/文件数 | 本期不展示，底层预留 | 后续音频参考及转码处理使用 |
| 重生成秒数 | 本期不展示，底层预留 | 后续 H3 regeneration 使用 |
| Provider token | 成本核算 | Seedance 实际 usage，不直接作为用户难以理解的前台单位 |
| 上下文 token | 本期不展示，底层预留 | 后续 Context-IR 使用 |

### 12.3 销售价格配置

价格策略采用“厂商成本上限 + 平台变动成本 + 目标毛利”的成本加成模型，不能只凭运营经验填写一个积分数。默认保护参数为：目标毛利率 25%、厂商成本波动缓冲 10%、支付手续费 3%、固定平台处理成本 0.15 元/成功结果、媒体处理与存储带宽准备金 0.02 元/输出秒。系统依据当前启用充值方式和固定积分包自动计算每积分净收入下限；默认 `1 积分 = 0.3125 元` 且允许最多 20% 套餐赠送时，保护值约为 `0.25260 元/积分`。

```text
安全销售积分 = 向上取整到 0.1 积分(
  (厂商成本上限 × 1.10 + 平台固定成本 + 输出秒数 × 平台每秒成本 + 参考素材处理成本)
  / 每积分净收入下限
  / (1 - 25%)
)
```

赠送积分属于获客预算，无法承诺单次使用产生现金收入；系统保证使用购买积分时不低于目标安全线，并单独统计赠送积分消耗对应的平台营销成本。

管理员按“路由模型 + 生成方式 + 清晰度 + 计量版本”配置或由系统生成价格。每条规则包括：

- 生效状态；
- 生效时间；
- 每输出秒积分；
- 可选固定任务积分；
- 参考图片、输入视频、参考音频和生成音频附加积分；
- 最低收费秒数或最小任务积分；
- 目标毛利、成本缓冲、平台成本和收入保护参数；
- 预留上浮比例：按秒精确计费候选默认 1.00，Seedance 等 token 波动候选默认 1.15；
- 内部备注。

路由模型某个完整参数组合的安全线取所有启用候选成本上限的最大值，避免 fallback 到更贵候选后亏损。规则优先级必须明确且可预览，不能依赖创建顺序。保存前后台应给出成本、建议积分、毛利和示例报价，例如“720P、5 秒、有声 = ◈X”。人工价格只能高于或等于安全线；低于安全线时禁止启用，而不是只显示警告。

### 12.4 预留与结算

```text
获取有效销售价格
  -> 计算预计/最高积分
  -> 校验余额
  -> 原子预留积分并创建任务
  -> 上游执行
  -> 成功后按实际成功产物结算
  -> 释放多余预留 / 失败全额释放
```

规则：

1. 任务和预留必须同时成功或同时失败。
2. 结算最多执行一次，重复回调和轮询不得重复扣费。
3. 若实际费用可能高于预留上限，平台必须在提交前提高上限，不允许成功后产生负余额。
4. 取消是否收费取决于厂商是否已成功生成，但前台只按最终成功产物结算；无法向厂商追回的内部成本由平台成本账本记录。
5. 多结果任务逐项结算，成功项收费、失败项退款。

### 12.5 用户账本展示

视频扣费记录展示：

- 类型：视频生成；
- 任务编号；
- 成功视频数量；
- 总输出秒数；
- 单位积分或计价摘要；
- 实际扣除积分；
- 预留释放金额；
- 创建和结算时间。

主界面金额保留两位小数；账单详情在必要时展示最多五位，保证汇总与账本一致，不使用前端浮点重新计算最终扣费。

### 12.6 管理员成本与毛利

每次真实厂商 attempt 记录：

- 厂商、真实账号和模型；
- 厂商任务 ID；
- 输入/输出 usage 原文；
- 标准化用量；
- 币种、汇率版本和成本；
- 用户销售积分折算收入；
- 任务毛利；
- 是否因平台重试产生未向用户收费的额外成本。

成本信息仅管理员可见。

## 13. 创意画布概览

### 13.1 产品定位

创意画布不是专业流程引擎，也不是视频剪辑器。它解决的是：

- 把提示词、图片输入和结果放在同一空间；
- 清楚表达“这个结果由哪些输入生成”；
- 从任意图片结果继续生图或生视频；
- 保留多条探索分支，随时回到之前的方案。

### 13.2 页面层级

```text
创意画布列表
  -> 新建画布
  -> 打开画布编辑器
       -> 添加节点/资产
       -> 连接输入
       -> 配置并主动生成
       -> 形成结果节点
```

### 13.3 画布与项目

1. 每个画布属于且只属于一个项目。
2. 画布列表默认显示当前项目的画布，支持切换项目。
3. 画布生成结果自动进入画布所属项目。
4. 画布可引用其他项目资产，但资产归属不变。
5. 删除项目时，画布与资产一起转移到用户指定目标项目；不得让画布失去项目。
6. 用户可在画布列表或画布设置中主动把整份画布转移到自己拥有的其他项目；只修改画布归属和后续生成结果的目标项目，不迁移画布引用的跨项目资产。

## 14. 创意画布列表

### 14.1 列表内容

每张画布卡展示：

- 自动生成的画布预览图；
- 画布名称；
- 所属项目；
- 节点数量；
- 最近修改时间；
- 正在运行/失败的任务数量；
- 打开、重命名、复制、转移项目、删除操作。

列表支持：

- 按名称模糊搜索；
- 按项目筛选；
- 按最近修改/创建时间排序；
- 手动刷新；
- 空状态创建入口。

### 14.2 新建画布

P0 提供以下模板：

| 模板 | 初始节点 |
| --- | --- |
| 图片探索 | 提示词节点 + 图片生成节点 |
| 图片转视频 | 图片节点 + 提示词节点 + 视频生成节点 |

创建弹窗包含名称和项目。名称默认“未命名画布”，同项目允许重名，但列表需通过时间和缩略图区分。

### 14.3 复制和删除

1. 复制画布只复制节点、连接、参数和资产引用，不复制媒体对象，也不复制任务运行状态。
2. 复制后的生成节点处于未运行状态，已有结果媒体节点仍引用现有资产。
3. 删除画布进入软删除/回收状态，不删除画布引用的资产。
4. 画布存在运行中任务时禁止删除，需先等待完成或申请取消。
5. 转移画布时只允许选择当前用户拥有且有效的目标项目；存在运行中生成任务时禁止转移，待任务结束或取消后再操作，保证画布及其生成结果始终使用同一项目语义。

## 15. 创意画布编辑器

### 15.1 编辑器布局

建议布局：

- 顶部左侧：返回画布列表、画布名称、所属项目；
- 顶部中间：选择/手型、添加节点、撤销/重做；
- 顶部右侧：保存状态、搜索、适应视图、小地图开关；
- 中央：可平移缩放的画布；
- 节点选中后：节点内或右侧轻量参数面板；
- 底部：缩放、适应视图、帮助和任务汇总。

不得在画布上长期占用大面积说明卡。首次空画布通过模板节点、工具栏和上下文操作帮助用户开始。

### 15.2 基础操作

P0 必须支持：

- 鼠标滚轮/触控板缩放；
- 拖拽空白处平移；
- Space 临时切换手型；
- 单选、多选、框选；
- 拖动节点；
- 删除、复制、粘贴、重复；
- 撤销和重做；
- 连线、选择和删除连接；
- 适应全部、聚焦选中节点；
- 自动保存和刷新恢复。

快捷键以平台常见约定为准，工具按钮必须提供 tooltip 和可访问名称。输入框编辑时不能被画布快捷键误删节点。

### 15.3 节点类型

| 节点 | 用途 | 可作为输入 | 可产生结果 |
| --- | --- | --- | --- |
| 提示词节点 | 编写可复用提示词模板和变量 | 图片/视频生成节点的提示词 | 否 |
| 图片节点 | 展示本地或平台图片资产 | 图片生成参考图、视频生成首帧/尾帧 | 否 |
| 视频节点 | 展示平台视频资产 | 本期不作为生成输入 | 否 |
| 音频节点 | 展示并播放平台音频资产 | 本期不作为生成输入 | 否 |
| 图片生成节点 | 配置并提交图片任务 | 提示词、图片 | 生成一个或多个图片节点 |
| 视频生成节点 | 配置并提交视频任务 | 提示词、首帧图片、P0 尾帧图片 | 生成一个或多个视频节点 |
| 便签节点 | 记录创作说明 | 不参与生成 | 否 |

节点头部必须通过名称和图标区分类型，状态色只辅助表达，不能只靠颜色区分。

### 15.4 添加节点

入口包括：

1. 顶部工具栏图标；
2. 画布空白处双击或右键的节点菜单；
3. 从连接端口拖到空白处，菜单只展示兼容节点；
4. 从资产抽屉拖入画布，形成媒体节点；
5. 媒体节点快捷操作“继续生图 / 生成视频”，自动在附近创建并连接对应生成节点。

节点新增位置应在当前视口中心或操作落点，不得每次堆叠到固定坐标。

### 15.5 连接规则

连接是有方向和类型的：

| 来源 | 目标 | 规则 |
| --- | --- | --- |
| 提示词 | 图片生成 | 作为提示词输入；一个生成节点可连接多个提示词，需选择一条路径或按明确顺序合并 |
| 提示词 | 视频生成 | 同上 |
| 图片 | 图片生成 | 作为参考图，数量不得超过模型分组上限 |
| 图片 | 视频生成 | 指定为首帧；可指定尾帧 |
| 图片生成 | 其他生成节点 | 不直接连接；应连接其实际结果图片节点 |
| 视频 | 任意生成节点 | 本期禁止，连接菜单不展示不合法目标 |
| 音频 | 任意生成节点 | 本期禁止，连接菜单不展示不合法目标 |
| 便签 | 任意节点 | 禁止业务连接 |

要求：

1. 不合法连接在拖动时即以视觉反馈拒绝，释放后不创建连接。
2. 形成循环时拒绝连接并提示“当前生成关系不能形成循环”。
3. 删除连接只移除输入关系，不删除节点或资产。
4. 同一图片连接到视频生成节点时默认成为首帧；若已有首帧，要求选择替换或作为尾帧，不静默覆盖。

### 15.6 提示词节点

1. 支持普通文本、`{{$变量}}`、`{{@资源}}` 和现有提示词优化。
2. Tag 展示、变量表单和无效状态与快捷创作保持一致。
3. 节点可重命名，默认名称“提示词”。
4. 多个提示词节点连接到一个生成节点时，一期优先让用户选择一条“当前提示词路径”，避免隐式拼接导致内容不可预测。
5. 生成任务保存当时解析后的提示词快照；后续编辑提示词节点不修改历史任务。

### 15.7 媒体节点

图片节点展示：

- 缩略图；
- 资产名称；
- 尺寸和来源；
- 查看详情、下载、继续生图、生成视频。

视频节点展示：

- 海报帧；
- 名称、时长和清晰度；
- 点击播放；
- 查看详情、下载、复用参数。

音频节点展示：

- 名称、时长和简化波形；
- 播放、暂停和当前播放位置；
- 查看详情和下载；
- 本期不显示不支持的音频生成或参考操作。

媒体节点引用资产，不保存永久签名 URL。签名过期时自动刷新。资产被用户从资产库删除但仍被画布引用时，节点标记“已从资产库删除，画布仍在引用”，媒体对象在引用释放前不得物理清理。

### 15.8 生成节点

生成节点保持紧凑，只展示常用字段：

- 模型分组；
- 提示词来源；
- 输入素材摘要；
- 常规参数；
- 预计积分；
- 生成按钮；
- 当前任务状态。

更多参数通过节点内展开区或右侧面板显示。不得把完整快捷创作页面塞入节点。

### 15.9 画布生成流程

1. 用户添加或连接提示词、图片。
2. 生成节点实时校验输入和参数。
3. 节点展示预计积分及当前余额。
4. 用户主动点击“生成”。
5. 节点进入排队/生成/保存状态，连接关系和参数快照锁定给本次任务。
6. 用户仍可编辑节点作为下一次草稿，但当前任务详情显示已提交快照。
7. 任务成功后，在生成节点右侧自动创建结果媒体节点并连接结果关系。
8. 多结果按规则排列，不能相互覆盖。

每次点击只执行当前节点，不自动执行其他节点。若上游输入节点尚未产生可用资产，生成按钮禁用并指明缺失输入。

### 15.10 任务恢复

1. 用户关闭页面后任务继续运行。
2. 再次打开画布时，根据任务 ID 恢复真实状态。
3. 上次保存时显示“生成中”但服务端已完成时，自动补建结果节点。
4. 任务成功但结果节点写入画布失败时，提供“恢复结果到画布”操作，不重新生成或扣费。
5. 断网期间的节点布局编辑保存在本地待同步，但生成提交必须确认服务器已接收。

### 15.11 自动保存与版本冲突

1. 节点、连接、视口和参数修改后短延迟自动保存。
2. 顶部状态只显示“保存中 / 已保存 / 保存失败”，不使用长期旋转状态掩盖失败。
3. 刷新或重新登录后恢复最近已保存版本。
4. 同一画布在两个标签页同时编辑时，后提交的过期版本不得直接覆盖新版本；提示刷新或复制为新画布。
5. 一期不提供面向用户的历史版本列表，但服务端应保留必要恢复能力，具体由技术设计确定。

### 15.12 易用性要求

1. 空画布默认将视口置于可开始工作的中心区域。
2. 从资产创建画布时，资产节点居中，并在附近提供兼容的快捷生成操作。
3. 新建生成节点时优先继承当前画布最近使用的模型分组和合法参数。
4. 连接图片到视频生成节点后自动切换为图片生成视频，但必须让状态变化可见。
5. 删除节点、断开连接和生成任务分别对待；普通布局操作不反复弹确认，涉及运行任务或未保存文本时才确认。
6. P0 支持自动整理选中节点，保持连线方向一致并避免节点重叠。
7. 画布搜索支持按节点名称、提示词片段和资产名称定位。
8. 小地图只展示结构和视口，不自动播放媒体。

### 15.13 移动端策略

1. 手机端允许查看画布、查看节点详情、查看任务状态、播放和下载结果。
2. 手机端允许对运行任务执行取消等必要操作。
3. 手机端不承诺节点创建、连线、框选和复杂布局编辑。
4. 尝试进入编辑操作时提供“请在桌面端编辑”的明确状态，不显示损坏或挤压的桌面工具栏。
5. 平板横屏必须开放完整画布编辑，包括节点创建、拖动、连线、框选、缩放、参数填写和主动生成；触控命中区、长按/双指手势和软键盘遮挡需单独验收。

## 16. 统一资产管理

### 16.1 资产信息架构

资产页顶部包含：

- 当前项目选择；
- 搜索；
- 媒体类型筛选；
- 来源筛选；
- 分组筛选；
- 排序；
- 刷新；
- 上传按钮；
- 批量选择入口。

筛选项：

| 维度 | 选项 |
| --- | --- |
| 媒体类型 | 全部、图片、视频、音频 |
| 来源 | 全部、平台生成、本地上传 |
| 项目 | 当前项目；允许切换，保持全站一致 |
| 分组 | 全部、未分组及用户分组 |
| 处理状态 | 可用、处理中、处理失败 |
| 排序 | 最近创建、最早创建、名称、文件大小、时长 |

搜索匹配资产名称。后续可扩展提示词搜索，本期不要求全文检索。

### 16.2 资产卡片

统一卡片包含选择控件、名称、媒体类型、来源和必要元信息，但预览区域按类型变化：

- 图片：固定宽度缩略图，保持实际比例；
- 视频：poster 海报，覆盖时长和播放图标；
- 音频：波形或音频图标，展示时长；
- 处理中：稳定占位，不因文案变化导致列表跳动；
- 失败：显示失败标识和重试处理入口。

图片和视频可使用瀑布流/自适应网格；“全部”视图必须保证卡片元信息对齐，不让极端比例媒体无限拉长列表。

### 16.3 本地上传

上传入口：

1. 资产页上传图标按钮；
2. 文件拖入资产页；
3. 快捷视频生成的首帧上传；
4. 创意画布的图片节点上传。

所有入口创建同一种本地上传资产。

上传体验：

- 支持多文件选择；
- 大文件分片上传；
- 上传托盘展示文件名、类型、大小、进度、速度和状态；
- 支持取消、失败重试；
- 页面切换后仍可查看当前会话上传状态；
- 文件上传完成后进入“正在处理”，必要派生文件完成后变为“可用”；
- 图片可在缩略图完成后使用；视频可在原文件校验通过后用于下载，在海报/预览完成后完整可预览；
- 上传文件默认属于当前项目，允许在开始前批量改选目标项目和分组。
- 单文件上传上限默认 1 GiB。S3/MinIO 必须使用分片直传；Local filesystem 模式也必须支持 1 GiB，但可以采用磁盘分块会话、断点续传和流式合并，不允许把 1 GiB 正文一次性读入 API 内存。

### 16.4 上传校验

1. 管理后台配置每种媒体允许的扩展名、MIME、单文件大小和时长上限。
2. 前端选择后立即做基础校验，后端及媒体处理任务再次做真实格式校验。
3. 文件扩展名与真实内容不一致时以后端检测为准并拒绝伪装文件。
4. 拒绝时说明具体文件和原因，其他合法文件继续上传。
5. 上传配额不足时展示当前用量、限制和需要释放的空间，不让文件上传完才发现无法入库。
6. 重名允许，不用文件名覆盖已有资产。

首期平台资产格式固定为：

- 图片：JPG/JPEG、PNG、WEBP，并纳入厂商已声明支持的 HEIC、HEIF、BMP、TIFF、GIF；列表和详情统一生成浏览器兼容的 WEBP/JPEG 派生图。
- 视频：至少支持 MP4，并支持 Seedance 声明的 MOV；真实内容仅接受 H.264/AVC、H.265/HEVC 视频轨以及 AAC/MP3 音频轨。平台详情统一播放 H.264/AAC MP4 proxy，原件保留下载。
- 音频：MP3、M4A、WAV。由于两家模型当前明确列出的独立参考音频格式是 WAV/MP3，M4A 若未来作为模型参考输入，平台先生成受控 MP3/WAV 参考派生件。

平台“可上传、可管理”与“某个真实模型可直接引用”是两层能力。路由前仍按模型能力矩阵校验格式，不得把 Seedance 独有的 MOV/BMP/TIFF/GIF 能力错误暴露给 MiniMax 候选。

### 16.5 图片预览

1. 列表加载缩略图，不加载原图。
2. 详情先加载中等尺寸预览，用户主动查看原图或下载时才请求原件。
3. 详情支持缩放、适应视图、实际尺寸查看和下载。
4. 保留现有生成参数、提示词、参考图和公开状态能力。

### 16.6 视频预览

1. 列表默认只加载海报帧。
2. 桌面端指针稳定悬停 150-300ms 后才加载 3-6 秒低码率静音预览。
3. 移出卡片后暂停；未完成请求允许取消。
4. 同一视口最多自动预览 1-2 个视频。
5. 手机端不使用 hover，点击后进入详情播放。
6. P0 详情统一播放 H.264/AAC faststart MP4 proxy；暂不生成 HLS。下载使用原文件，MOV 等浏览器兼容性不足的原件不直接承担页面播放。
7. 原文件无法被浏览器直接播放但可被平台识别时，详情明确显示“已生成兼容预览，下载仍为原文件”。

### 16.7 音频预览

1. 列表只加载波形数据和时长，不预加载音频正文。
2. 点击播放后请求低码率兼容音频。
3. 同一时间只播放一个资产；开始新音频时停止上一个。
4. 详情支持播放、暂停、拖动、音量、当前时间/总时长和下载。

### 16.8 资产详情

通用信息：

- 名称和可编辑名称；
- 媒体类型、格式、大小；
- 项目、分组和来源；
- 创建时间；
- 原文件下载；
- 添加到创意画布；
- 转移项目、设置分组、删除。

图片增加尺寸和现有生成信息。视频增加时长、比例、清晰度、编码和视频生成参数。音频增加时长、采样率、声道等可用元数据。

生成资产还应关联任务详情和实际积分；本地上传资产不展示虚构生成参数。

### 16.9 从资产继续创作

| 资产类型 | 快捷操作 |
| --- | --- |
| 图片 | 继续生图、生成视频、添加到画布 |
| 视频 | 复用视频参数、添加到画布 |
| 音频 | 添加到画布；本期画布内仅展示和播放，不参与生成 |

“复用视频参数”带入模型分组、提示词模板、时长、比例、清晰度和音频开关；不复制上次变量值。原结果图片若作为首帧，必须由用户明确选择“用作首帧”，不能因复用参数自动绑定。

### 16.10 批量操作

在现有图片批量能力上扩展到多媒体：

- 全选当前筛选结果；
- 反选当前已加载范围；
- 清空选择；
- 打包下载；
- 设置分组；
- 转移项目；
- 删除。

“批量公开”仅对图片可用。混合选择中若包含视频或音频，应只处理图片并提前显示适用数量，或要求用户筛选图片后执行；不得让不支持项静默失败。

批量操作返回逐项结果。成功项从选中集合移除，失败项保留供重试。

### 16.11 删除与引用

1. 删除后资产立即从普通资产查询中隐藏。
2. 资产被创意画布、生成任务或其他有效记录引用时，物理文件继续保留。
3. 画布中的已删除资产节点仍可查看，并标记其资产库状态。
4. 用户从所有画布移除引用且不存在其他有效引用后，进入对象存储异步清理。
5. 删除画布不删除其引用资产。
6. 删除生成任务历史不应绕过资产引用保护。

## 17. 管理后台需求

### 17.1 接入账号与真实模型

账号增加 Provider 类型：

- Seedance/火山方舟；
- MiniMax。

首发真实模型固定为：

- `doubao-seedance-2-5-260628`（Seedance 2.5）；
- `doubao-seedance-2-0-260128`（Seedance 2.0）；
- `MiniMax-H3`（MiniMax H3）。

模型代码仍按版本化配置保存，后续厂商换代不得覆盖历史任务快照。

真实视频模型配置至少包括：

- 模型代码和展示名称；
- 支持的生成方式；
- 支持的时长范围/枚举；
- 支持的比例；
- 支持的清晰度；
- 是否支持首帧、尾帧；
- 是否支持生成音频；
- 输入素材数量、大小和时长限制；
- 单次 Provider 请求原生最大结果数，配置范围 1-10；该值不改变平台把用户生成数量拆成独立任务的现有逻辑；
- 并发和限流；
- 启用状态；
- 厂商成本规则及币种；
- Provider 专属但经过白名单的配置。

保存前校验参数组合，不能只校验每个枚举单独合法。

真实模型编辑页内嵌“成本规则”子面板，配置厂商计费模式、各分辨率/输入类型单价、token 单价、生效区间和币种；成本规则仍保留独立版本和审计，不能与账号密钥一起覆盖保存。

### 17.2 路由模型/模型分组

路由模型增加媒体类型“视频”，并配置：

- 用户展示名称、描述和排序；
- 支持的生成方式；
- 默认时长、比例、清晰度和音频开关；
- 用户可见选项；
- P0 最大生成数量 1-4；
- 候选真实模型和路由权重；
- 绑定的视频价格策略及可选只加价倍率；
- 用户组可见性；
- 启用状态。

管理后台提供“有效能力预览”，显示当前配置下用户最终能看到的参数组合和缺失候选风险。

### 17.3 视频价格策略

新增视频价格管理视图，不强行复用图片分辨率价格行。

该页面作为真实模型成本与路由模型销售价之间的中间层：真实模型提供成本输入，价格策略定义目标毛利和销售计算规则，路由模型绑定策略并按完整候选集合生成安全销售价。

列表支持：

- 路由模型、生成方式、清晰度筛选；
- 生效状态筛选；
- 生效时间和价格排序；
- 新增、编辑、启用/禁用和删除；
- 示例价格试算；
- 每积分净收入下限、目标毛利、成本缓冲、支付手续费、平台固定/每秒成本、参考素材处理成本、生成音频附加、最低任务价和 reserve markup；
- 厂商成本、建议积分、人工销售积分、预计毛利的并列预览；
- “从真实模型成本重新计算”操作和受影响路由预览。

配置不完整、候选存在但无适用价格、售价低于安全线或积分套餐使净收入跌破策略保护值时，路由模型不得对用户可用，并进入上线检查风险。真实模型、价格策略和路由模型页面均提供互相跳转及影响摘要，但保持三类数据独立版本化，避免一次编辑级联覆盖历史记录。

### 17.4 视频任务运营

管理员任务列表支持：

- 用户、平台任务 ID、厂商任务 ID、项目、模型分组、真实模型筛选；
- 状态、时间范围筛选；
- 查看每次 attempt、耗时、脱敏错误、usage、成本和结算；
- 对“结果保存失败”执行重新转存；
- 对预览处理失败执行重新处理；
- 对最终失败任务查看退款状态；
- 手动刷新。

“重新转存”和“重新处理”不得重新请求模型生成。

### 17.5 媒体策略

系统设置增加：

- 各媒体类型允许格式；
- 单文件最大大小；
- 视频最长时长；
- 用户总存储配额和可选用户组覆盖；
- 图片缩略图档位；
- 视频 poster、hover preview、详情 proxy 策略；
- 音频 proxy 和波形策略；
- 临时上传、失败处理和软删除保留期。

配置变更只影响新上传或后续重建，不静默破坏历史资产。

### 17.6 上线检查

增加以下检查：

- 至少一个启用的视频路由模型；
- 每个启用视频路由存在可用候选；
- 每个可见参数组合存在价格；
- 对象存储可写、可读和签名；
- 媒体处理 Worker 在线；
- 视频结果转存积压；
- 派生资源处理积压；
- 最近一段时间重复结算或待退款异常。

视频功能可独立开关。未通过视频检查时可以只关闭视频入口，不影响现有图片生成。

## 18. 任务与资产关系

### 18.1 生成结果

1. 每个成功图片或视频结果自动形成一个资产。
2. 任务历史负责解释一次提交，资产负责长期复用和管理。
3. 删除任务历史不删除资产；删除资产不删除计费和任务审计。
4. 一个任务多个结果时，每个结果是独立资产，共享父任务信息。

### 18.2 画布引用

1. 画布节点引用资产 ID 和任务 ID，不复制媒体对象。
2. 同一资产可被多个画布引用。
3. 画布复制继续引用同一资产。
4. 画布生成结果同时关联生成节点、任务和资产，方便恢复。

### 18.3 本地上传来源

本地上传直接创建资产，不创建伪生成任务。上传处理可有独立处理任务，但不得在用户账单中显示为生成扣费。

## 19. 权限、安全与内容合规

1. 用户只能读取、修改和引用自己拥有的项目、画布和资产。
2. 跨项目引用仍必须是同一用户所有；本期不支持跨用户引用私有资产。
3. 原文件和私有派生资源使用短时签名访问，画布不得保存永久 URL。
4. 应用 API 不代理大媒体正文，避免带宽和内存风险。
5. 上传内容进行格式、安全和内容策略检查；检查中资产不可作为生成输入。
6. 视频生成执行厂商和平台内容安全规则，保存可审计但脱敏的拒绝原因。
7. Seedance 真人参考等特殊合规能力在未完成授权链路前不得开放。
8. 文件名、媒体元数据和 Prompt 在展示时进行安全转义。
9. 删除和下载、生成、计费、管理员重试等关键操作记录审计事件。

## 20. 性能与体验要求

### 20.1 快捷创作

1. 参数本地切换即时反馈，不依赖每次点击都等待完整页面接口。
2. 费用预估在正常网络下应在参数停止变化后尽快返回，并防止旧响应覆盖新参数。
3. 任务状态优先使用实时通道，断线后回退轮询；恢复后不得出现状态倒退。

### 20.2 创意画布

以 200 个节点、300 条连接、其中 50 个媒体节点作为首期基准工程：

- 打开后 3 秒内展示可操作骨架和已缓存预览；
- 常用拖动、框选和缩放不出现持续明显卡顿；
- 单次普通交互主线程长任务目标小于 100ms；
- 只加载视口附近媒体预览；
- 同时播放的视频节点不超过 2 个；
- 自动保存采用合并策略，连续拖动不逐像素提交请求。

若复用 Nova 实现无法达到基准，应在技术设计中明确虚拟化、空间索引或节点上限方案，不能通过不提示地丢弃节点解决。

### 20.3 资产页

1. 首屏只加载缩略图、海报或波形，不加载原文件。
2. 列表分页或游标加载，不一次读取用户全部资产。
3. hover 视频预览有延迟、并发上限和取消能力。
4. 大文件上传不经过 API 服务器，支持分片失败重试。
5. 手动刷新只刷新列表数据，不强制重新下载浏览器已缓存的有效派生资源。

## 21. 可访问性与输入方式

1. 图片/视频模式切换、模型分组、参数和生成按钮可使用键盘操作。
2. 画布工具按钮使用熟悉图标并提供 tooltip、可访问名称和焦点样式。
3. 生成任务状态同时使用文案、图标和颜色。
4. 视频播放器、音频播放器提供键盘播放/暂停和可读时间信息。
5. 尊重减少动态效果设置；hover preview 在减少动态效果时默认不自动播放。
6. 画布核心节点可通过节点搜索定位；完整键盘连线属于后续增强，但不得阻止键盘用户查看和编辑节点表单。

## 22. 数据埋点与运营观测

### 22.1 用户行为

至少记录：

- 切换图片/视频模式；
- 选择生成方式和模型分组；
- 费用预估成功/失败；
- 视频提交、取消、成功、失败、保存完成；
- 从资产复用、从任务复用；
- 创建/打开/复制/删除画布；
- 添加节点、建立连接、节点生成；
- 本地上传开始、成功、失败；
- 图片/视频/音频预览和下载。

埋点不记录完整 Prompt、变量值、签名 URL 或用户媒体内容。

### 22.2 运营指标

按模型分组和真实模型观察：

- 请求量、成功率、P50/P90/P99 耗时；
- 排队、生成、转存、派生处理分阶段耗时；
- 用户销售积分、厂商成本和毛利；
- fallback 和额外内部成本；
- 上游成功但转存失败数量；
- 重复回调、重复结算拦截数量；
- 对象存储容量、原件/派生比例和 CDN 命中率。

## 23. 迁移与兼容

### 23.1 现有图片创作

1. 原图片创作入口和深链接继续有效。
2. 进入“创作”默认保持图片模式，除非用户主动切换或从视频操作进入。
3. 现有图片任务、提示词模板和草稿继续可读。
4. 视频接入不修改现有图片数量拆分、fallback 和计费规则。

### 23.2 现有图片资产

1. 历史图片在统一资产页继续可见。
2. 迁移过程中不得复制原图对象。
3. 允许通过兼容读取或渐进迁移接入统一资产模型。
4. 历史图片缺少新派生资源时按需生成或使用现有预览，不阻塞资产页上线。

### 23.3 项目

1. 现有默认项目和全站项目记忆保持有效。
2. 视频、上传资产和画布若未显式指定项目，使用当前有效项目；当前项目失效时回退默认项目。
3. 项目删除流程必须同时处理画布、图片、视频和音频，不允许遗漏新媒体类型。

### 23.4 功能开关与灰度

建议独立开关：

- 视频快捷创作；
- 创意画布；
- 本地多媒体上传；
- 具体视频路由模型可见性。

灰度期间对未开放用户隐藏入口，但历史任务和资产详情仍可访问，避免功能关闭后用户无法取回结果。

## 24. 异常与边界场景

### 24.1 能力和价格变化

- 用户打开旧草稿时模型已禁用：保留内容，要求重新选择模型。
- 参数选项已下线：标出失效字段并提供合法默认值，不自动提交。
- 管理员提交后改价：已创建任务按价格快照结算。
- 路由候选临时不可用：在能力允许范围内 fallback；不得改变用户参数。

### 24.2 上传和处理

- 页面关闭：已直传的分片按上传会话恢复或过期清理。
- 原文件上传成功但回调丢失：后台可对账并恢复资产。
- 派生处理失败：原件状态与预览状态分开，允许管理员重试。
- 存储配额在并发上传中被占满：完成确认时原子校验，超限文件不进入可用资产并清理临时对象。

### 24.3 画布

- 连接的资产被删除：节点保留并标记引用状态。
- 任务完成时用户已删除生成节点：结果仍进入资产，画布提供未归位结果提示或不自动恢复被用户明确删除的节点。
- 画布保存冲突：禁止静默覆盖，允许刷新或复制本地版本。
- 画布加载部分媒体失败：布局和文本仍可编辑，单个媒体节点提供重试。

### 24.4 计费

- 预留成功但任务创建失败：同一事务或补偿立即释放预留。
- 重复 callback/轮询：同一任务最多结算一次。
- 上游返回成功但无文件：按失败处理，不扣生成费并记录厂商异常。
- 多结果部分成功：只收成功项，失败项释放预留。
- 管理员重新转存/重新处理：不产生用户生成扣费。

## 25. 验收标准

### 25.1 快捷视频生成

1. 用户可在同一创作页切换图片和视频，现有图片生成流程无回归。
2. 用户可完成文生视频和单首帧图生视频。
3. 每个模型分组只展示真实可用且有价格的参数组合。
4. 切换模型导致参数变化时，用户能看到具体变化，平台不静默降级。
5. 提交前展示与参数一致的预计或最高预留积分；旧预估不能提交。
6. 余额不足、参数错误和素材错误均指向明确原因并保留草稿。
7. 任务展示排队、生成、保存、预览处理和完成等真实阶段，不伪造进度。
8. Seedance 与 MiniMax 成功结果在厂商 URL 失效前转存，并自动形成视频资产。
9. 上游失败全额释放预留；部分成功仅对成功视频收费。
10. 重复回调、重复轮询和用户重复点击不会创建重复结算。
11. 用户能在任务详情核对参数、预计/实际/退回积分和结果。
12. 复用视频任务不会复制上次变量值，也不会自动绑定原首帧。

### 25.2 视频计费与后台

1. 管理员可配置视频真实模型能力、路由候选和视频价格规则。
2. 后台能预览一个参数组合的用户报价，并阻止有候选无价格的路由上线。
3. 任务保存销售价格、厂商成本和 usage 快照。
4. 用户账本总额与任务结算一致，主金额和五位精度详情不矛盾。
5. 管理员可定位转存失败、预览失败和退款异常，重试处理不重新生成、不重复扣费。
6. 视频功能检查失败可以单独关闭视频，不影响图片生成。
7. 真实模型成本、价格策略和路由模型三处配置可互相查看影响摘要，但修改不会覆盖历史版本和任务快照。
8. 人工售价低于候选最坏成本安全线，或有效积分商品使每积分净收入跌破保护值时，后台拒绝启用相关视频路由并指出原因。

### 25.3 创意画布

1. 用户可创建、重命名、复制、删除和重新打开画布。
2. 画布属于项目，生成结果始终进入画布所属项目。
3. 用户可添加提示词、图片、视频、音频、图片生成、视频生成和便签节点。
4. 用户可完成框选、移动、连线、删除、复制粘贴、撤销重做、缩放和平移。
5. 不合法连接和循环连接被阻止，已有输入不被静默覆盖。
6. 用户可从提示词和图片节点输入生成图片或视频，提交前看到费用。
7. 每次只主动执行当前生成节点，连接变化不会自动扣费。
8. 任务完成后自动创建并连接结果媒体节点，刷新页面后可恢复。
9. 自动保存失败和多标签冲突均有明确提示，不静默覆盖。
10. 200 节点/300 连接基准画布保持可操作，媒体按视口懒加载。
11. 手机端可以可靠查看结果和任务，不展示不可用的完整桌面编辑器。
12. 用户可把无运行中任务的画布转移到其他自有项目，画布引用资产不被迁移或复制，后续生成结果进入新项目。
13. 平板横屏支持节点创建、拖动、连线、框选、缩放、参数填写和主动生成等完整编辑能力。

### 25.4 统一资产

1. 历史图片、生成视频和本地上传媒体可在同一资产页按项目查看。
2. 用户可批量上传支持的图片、视频和音频，非法文件逐项提示且不影响合法文件。
3. 上传成功资产被归类为“本地上传”，重名不覆盖旧资产。
4. 图片列表使用缩略图，视频列表默认 poster，音频列表默认波形，不预加载原文件。
5. 视频 hover 预览有延迟、取消和并发限制；移动端点击进入详情。
6. 用户可预览、下载、重命名、分组、转移项目和删除三类资产。
7. 图片可继续生图/生视频，视频可复用参数，三类资产可添加到画布。
8. 批量操作返回逐项结果，失败项保持选中。
9. 删除被画布引用的资产后，业务列表立即隐藏，但对象在引用释放前不物理删除。
10. 应用 API 不代理大文件上传、预览和下载正文。

## 26. 发布前检查清单

### 产品与体验

- 图片模式回归通过；
- 两家厂商至少各有一个可用路由模型；
- 所有用户可见组合都能成功估价；
- 空状态、加载、无余额、无模型、处理失败状态齐全；
- 桌面和移动端无重叠、溢出或不可取回结果的入口。
- AI 开发代理先按现有设计系统完成桌面、手机和平板横屏视觉与交互验收，输出截图和问题清单；项目所有者随后进行最终人工验收。

### 计费

- 成功、失败、取消、超时、重复回调、部分成功用例通过；
- 预留、扣除、释放和账本总额可对账；
- 厂商 usage 和成本快照可查；
- 上游成功但转存失败不重复收费。

### 媒体

- 上传格式、大小、时长和配额校验通过；
- 图片缩略图、视频 poster/preview/proxy、音频波形/proxy 生成通过；
- 签名 URL 过期后各页面可恢复；
- 删除、引用保护和对象清理通过。

### 画布

- 云端保存、刷新恢复、多标签冲突通过；
- 生成中关闭页面并重新打开可恢复；
- 结果节点补建不重复生成；
- 基准节点规模性能通过；
- 画布主动转移项目、项目删除转移和运行中禁止转移通过；
- 平板横屏完整编辑、触控手势和软键盘遮挡验收通过；
- 已记录“项目所有者通过线下沟通取得 Nova 商业授权”的事实，仓库中不伪造不存在的授权证明；Nova 第三方依赖许可证检查通过。

## 27. 风险与产品控制

| 风险 | 产品影响 | 控制措施 |
| --- | --- | --- |
| 视频成本高且成功率波动 | 用户不敢尝试或产生费用争议 | 明确预估/上限、失败退款、真实状态、按模型展示质量与速度定位 |
| 厂商能力变化快 | 已配置参数突然不可用 | 能力版本化、模型级功能开关、上线检查、保留草稿 |
| 视频任务耗时长 | 用户重复提交 | 阶段状态、任务持久化、提交幂等、明显的当前任务入口 |
| 结果 URL 限时 | 生成成功但资产丢失 | 独立“正在保存”状态、高优先级转存、管理员恢复入口 |
| 画布过于专业 | 新用户无法开始 | 保留快捷创作、模板、上下文快捷动作、紧凑生成节点 |
| 画布自动执行误扣费 | 信任受损 | 一期只允许节点手动执行，每次展示费用 |
