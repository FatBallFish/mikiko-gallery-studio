# 创作台资产导入与上传限制统一需求

日期：2026-11-03

## 背景

统一媒体资产改造（`docs/prd/2026-11-01-unified-media-references-requirements.md`）落地后，创作台上传的图片进入统一资产库（资产页可见），但"从资产导入"弹窗仍只展示生成结果图，用户找不到自己上传的图片。同时，各模型上传附件的大小提示来源分散：GPT/统一上传走平台附件策略（默认 20MB），native 模型（万象/即梦）走前后端硬编码（10/30MB），观感不一致。

## 需求

1. 创作台"从资产导入"弹窗必须同时展示当前项目的上传图片与生成图片；两类资产都可选中并导入为当前型号的参考图。
   - 弹窗提供"来源"筛选（全部/上传图片/生成图片）；搜索命中上传资产名称。
   - 混合选择时按来源分流：上传资产直接以统一媒体 ID 投影为参考图（不创建 reference alias），生成图沿用 `import-from-gallery`（携带生成快照）。
   - 导入前沿用现有按型号的格式/大小校验；上传资产无预览 URL 时按需懒加载缩略图。
2. 上传大小限制统一为单一配置源：`min(平台附件策略, 上游模型硬限制)`。
   - 平台附件策略 = 管理后台"附件策略"`image_max_mb`（默认 20MB），调整后全局生效。
   - 上游硬限制为供应商事实（qwen_image 10MB、seedream_image 30MB），后端在调用供应商前兜底校验，前端展示与选择校验取 min。
   - 不放宽上游限制：万象 10MB 源于阿里云 qwen-image-edit 官方限制，后端原样 base64 上传。

## 验收

- 上传一张图片后，重新打开"从资产导入"可以找到并导入它。
- 选择万象型号时上传入口与资产导入校验显示 10MB；即梦/其他 native 型号与 GPT/统一上传显示平台策略值（默认 20MB）。
- 管理后台调整 `image_max_mb` 后，各处展示随之下调（不超过上游硬限制）。
