# v0.0.19 管理后台与统一资产热修复需求

## 1. 背景

v0.0.18 上线后，管理后台接入账号页在尚未配置视频能力、成本、价格或路由时出现白屏；用户端统一资产页同时出现历史图片无预览、拖拽圈选回归和批量工具条未稳定悬浮的问题。本次热修复不新增业务能力，只恢复既有页面的可用性和交互契约。

## 2. 范围

### 2.1 管理后台空配置兼容

- `GET /api/ops/video/configuration` 的所有集合字段必须始终返回 JSON 数组，空集合输出 `[]`，不得输出 `null`。
- 管理后台 API 适配层必须兼容旧服务或异常代理返回的 `null`/缺失集合，将其规范化为空数组。
- 接入账号、价格策略和路由模型页面在视频配置为空时正常展示，影响摘要显示数量为 0，不得白屏。
- 不修改现有视频配置数据和数据库结构。

### 2.2 统一资产预览

- 图片资产卡片展示图片预览，优先使用 640/320 缩略图。
- 历史图片统一资产回填后若尚无缩略图派生，可使用该历史图片已有的私有原图访问作为兼容预览，不要求发布或升级时额外迁移。
- 新生成或本地上传图片仍按媒体处理链生成并使用缩略图；视频列表使用 poster，音频列表使用 waveform，不为列表主动加载视频、音频原文件。
- 预览加载失败时保留占位状态，不导致列表或页面崩溃。

### 2.3 拖拽框选

- 桌面端用户可在资产网格背景或资产预览画面按下主鼠标键并拖动，显示清晰的矩形选区。
- 与选区相交的已加载资产加入选择；从空白处开始拖拽时以本次命中结果替换原选择，按住 Command/Ctrl/Shift 时在原选择基础上追加。
- 小幅点击、滚动手势、从选择/播放/重试等独立卡片控件或筛选/批量操作控件开始的操作不得误触框选；资产预览画面本身是允许开始圈选的主命中区。
- 完成一次有效框选后，应抑制紧随其后的卡片打开行为；选择模式下点击卡片继续切换选择而非打开详情。
- 触摸设备不启用框选；移动端保持点击选择。

### 2.4 批量工具条悬浮

- 存在选择项时，批量工具条通过顶层 portal 固定悬浮在可视窗口底部，不受资产列表高度、父级布局或滚动位置影响。
- 工具条不得被页面内容遮挡；桌面端避开侧栏，窄屏可横向滚动且不溢出视口。
- 没有选择项时不展示工具条。

## 3. 验收标准

1. 全新或无视频配置的环境访问 `#/access-accounts`，页面无 JavaScript 异常，摘要各集合数量均为 0。
2. 后端空快照序列化结果中的 `capabilities`、`cost_rules`、`pricing_strategies`、`price_rules`、`routes`、`point_products`、`impacts` 均为 `[]`。
3. 历史回填图片资产可以在统一资产列表中显示预览；存在缩略图时仍优先请求缩略图对象。
4. 鼠标拖拽经过多张资产时可一次选中，选区实时可见，交互控件不触发框选。
5. 滚动到列表任意位置，批量工具条始终固定于窗口底部并可操作。
6. 用户端与管理后台 typecheck/build、Go 测试与全仓验证通过。

## 4. 非目标

- 不在本次热修复中补跑历史媒体派生任务。
- 不改变资产回填、上传、转码、计费和发布流程。
- 不修改视频配置业务校验规则。
- 不发布 tag 或部署生产环境，除非用户另行明确授权。
