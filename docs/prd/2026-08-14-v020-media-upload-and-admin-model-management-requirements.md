# v0.0.20 媒体上传与模型管理优化需求

## 1. 文档信息

- 文档状态：待开发
- 编写日期：2026-08-14
- 代码基线：远端 `main`，提交 `4aca7a2`，版本 `v0.0.19`
- 目标版本：暂定 `v0.0.20`
- 配套技术方案：`docs/tech/2026-08-14-v020-media-upload-and-admin-model-management-tech-design.md`
- 本期性质：用户端媒体资产链路补全、管理后台信息架构重构及稳定性修复

## 2. 背景与问题

平台已经具备统一媒体资产、分片上传、上传任务队列、图片/视频派生资源和视频模型配置等基础能力，但仍存在以下断点：

1. 创作页本地上传继续使用旧的 `reference_assets` 上传链路，上传结果不会进入统一资产列表。
2. 提示词编辑器无法从剪切板直接粘贴图片并完成上传与引用。
3. 资产页上传入口受站点级功能开关控制；当前线上无法开启该开关，不能直接归因于功能默认关闭，已确认管理后台保存时使用了错误的配置 Tab 路径。
4. 资产卡片只请求缩略图，没有合理的预览降级链路；派生资源缺失或未就绪时长期显示占位符。
5. 资产页的资产详情组件与首页、创作页的图片详情组件行为不一致，图片和视频在详情中无法再次打开全屏预览，音频和文档也缺少对应的媒体阅读能力。
6. 管理后台的视频账号、模型、路由和价格配置以独立工作台散落在图片配置页面中，无法清楚表达账号、真实模型、路由和价格的层级关系。
7. 文本模型配置位于系统设置，不利于统一管理模型能力。
8. 视频任务接口在空列表时可能返回 `items: null`，前端访问 `length` 后页面崩溃。
9. 菜单名称和页面归属仍沿用旧的图片平台语义。

## 3. 产品目标

### 3.1 用户端目标

- 所有本地上传媒体统一进入资产库，并明确标记来源为“本地上传”。
- 创作页、资产页和剪切板上传共用同一套上传能力与任务队列。
- 上传完成的图片可以立即加入当前图片编辑引用，不产生重复对象存储文件。
- 资产卡片在缩略图不可用时仍能可靠展示图片预览。
- 资产详情在图片、视频、音频和文档类型下提供符合媒体特征的预览交互，并与首页、创作页保持一致的全屏查看体验。
- 批量上传过程透明，可查看每个文件的进度和失败原因。

### 3.2 管理后台目标

- 接入账号、路由模型和价格策略按图片、视频、音频、文本四类组织。
- 视频配置采用与图片一致的“账号列表 + 真实模型列表”层级，不再要求管理员手填关联 ID 完成主要操作。
- 音频作为预留分类，展示明确空状态，不在本期接入运行能力。
- 文本模型从系统设置迁移到模型管理入口，同时保持现有运行逻辑不变。
- 媒体策略归入系统设置，并保留旧地址兼容。
- 视频任务空数据、异常数据不得导致页面崩溃。

## 4. 范围定义

### 4.1 本期范围

1. 创作页本地上传图片写入统一资产库。
2. 提示词编辑器支持粘贴剪切板图片。
3. 资产页提供批量上传入口和上传任务列表。
4. 资产预览建立缩略图、预览图、原图降级链路。
5. 资产详情支持图片、视频、音频和文档预览，其他类型明确展示暂不支持预览。
6. 接入账号按媒体类型拆分并重构视频账号、模型管理。
7. 路由模型按媒体类型拆分并重构视频路由管理。
8. 价格策略按媒体类型拆分并重构视频价格管理。
9. 文本模型配置迁移到模型管理入口。
10. 修复视频任务空列表崩溃。
11. “调用记录”更名为“图片任务”。
12. 媒体策略迁移至系统设置“附件策略”右侧。

### 4.2 非本期范围

- 不改变视频模型运行时的候选权重、自动故障回退和调度算法。
- 不新增音频生成模型、音频路由和音频计费能力。
- 不在本期将文本模型运行时重构为完整的通用路由模型。
- 不复制已存在的对象存储文件来建立创作引用。
- 不删除旧的 `#/call-records` 和 `#/media-policy` 兼容路由。
- 不改变现有图片生成任务 API 和历史账单快照。

## 5. 用户端需求

### 5.1 创作页本地上传自动进入资产库

#### 用户故事

用户在创作页添加本地图片作为编辑来源后，应能在当前项目的资产页找到该图片，不需要重复上传。

#### 交互与规则

- 上传文件默认归属当前选中的项目。
- 统一资产记录使用 `source_type=local_upload`。
- 默认名称取原文件名；重名时沿用平台现有唯一命名规则。
- 上传完成后自动加入当前创作页的图片编辑引用列表。
- 上传完成后资产页自动刷新；不要求用户手动刷新或切换页面。
- 同一文件在一次上传任务中不得重复创建资产。
- 建立创作引用时只创建关联，不复制或重新上传对象存储文件。
- 当前模型的参考图数量、格式和体积限制继续生效。
- 跨项目引用保持允许；引用关系不随资产项目迁移失效。

### 5.2 提示词编辑器粘贴图片

- 紧凑提示词编辑器和展开弹窗内的编辑器均支持 `Ctrl+V` 和 `Cmd+V`。
- 若剪切板包含一张或多张图片：
  - 阻止浏览器把图片当普通内容粘贴；
  - 将图片加入统一上传任务队列；
  - 上传到当前项目；
  - 上传完成后加入图片编辑来源；
  - 在当前光标位置插入对应的资产引用 Token。
- 若剪切板不含图片，完全保留现有文本粘贴行为。
- 若剪切板同时包含图片和文本，以图片上传为主，不额外插入剪切板中的富文本替代内容。
- 多张图片受当前模型剩余引用数量限制，超出部分明确提示并跳过。
- 文件类型、大小或上传失败必须展示具体错误，不能静默失败。
- 粘贴触发上传后，用户可在全局上传任务列表查看进度。

### 5.3 资产页批量上传

- 资产页页头提供图标按钮作为上传入口，包含可访问名称和 tooltip。
- 支持一次选择多个图片、视频和音频文件。
- 本期上传入口至少支持：图片 `jpg/jpeg`、`png`、`webp`；视频 `mp4`；音频 `mp3`、`m4a`、`wav`。前端按扩展名和 MIME 双重校验，后端以实际探测结果为准，拒绝伪造 MIME 或不在白名单内的文件。
- 单文件大小上限沿用媒体策略配置，最大不超过 1 GiB；超过限制时在任务列表中逐项标记失败，不影响其他文件上传。
- 文档预览兼容已有文档类资产；本期不因预览需求额外开放未定义的文档上传格式。若媒体策略已经允许文本文档，仍必须经过后端类型白名单和大小限制。
- 上传任务列表展示：
  - 文件名；
  - 媒体类型；
  - 文件大小；
  - 当前状态；
  - 单项进度；
  - 失败原因；
  - 暂停、继续、重试、取消操作。
- 页面切换后仍保留当前会话内的上传任务信息。
- 上传完成后自动刷新当前项目资产列表。
- 上传任务必须携带客户端幂等键；重复点击完成、网络重试或同一批次重放不得创建重复 `MediaAsset`。服务端需以用户、幂等键和文件校验摘要（若可获得）共同保证幂等。
- `media_upload` 保留为站点级可配置开关，由管理后台决定是否开启。本期不改变当前默认值，也不通过升级初始化覆盖管理员已有配置。
- 管理后台保存功能开关时必须写入 `site` Tab；`features` 是配置分类，不是 Tab key。保存前读取最新的 `site.version`，保存失败时展示明确错误，不能让用户误判为功能不存在或默认关闭。

### 5.4 资产预览降级

#### 图片

按以下顺序获取预览：

1. `thumbnail`
2. `preview`
3. 原始图片访问地址
4. 类型占位图与可识别错误状态

规则：

- `ready` 和 `ready_original` 图片均必须尝试获取预览。
- 缩略图不存在、未就绪或请求失败时，自动进入下一层级。
- 原图仅作为降级方案，不能成为瀑布流的默认首选，以控制带宽和对象存储流量。
- 前端渲染预览时只请求 `thumbnail` 和 `preview` 用途；原图降级由服务端在 `preview` 用途中按策略返回，不能把 `download` 用途地址直接用于瀑布流或详情静态 `<img>`。
- 临时 URL 过期或图片加载失败时，可重新获取一次当前层级；仍失败后继续降级。
- 派生处理中可以使用原图预览，但要保留处理状态提示。
- 页面刷新、项目切换后必须重新获取必要的访问地址。

#### 视频和音频

- 视频保持 `poster -> hover/proxy` 的现有策略。
- 音频保持 `waveform -> preview/proxy` 的现有策略。
- 视频上传或生成完成后，媒体处理任务应异步生成可用于资产列表和详情静态展示的 poster；poster 未就绪时展示处理状态，不得在列表中自动拉取完整视频。
- 音频上传完成后，媒体处理任务应按支持情况生成 waveform/时长元数据；waveform 未就绪时仍可点击后使用预览流播放。
- 派生资源缺失时展示明确状态，不得引发组件崩溃。

### 5.5 资产详情统一预览

资产详情组件需要与首页、创作页的图片详情组件统一预览能力。用户在详情组件中再次点击媒体主体时，按媒体类型执行以下行为：

#### 图片

- 详情页先展示当前可用的缩略图、预览图或原图降级资源。
- 点击图片后打开全屏图片查看器，复用首页和创作页现有的图片预览组件。
- 全屏查看器支持放大、缩小、拖拽平移、适应窗口和关闭；图片加载失败时沿用缩略图、预览图、原图的降级顺序。
- 打开和关闭全屏查看器不得丢失当前资产详情的编辑状态、项目上下文和选中状态。

#### 视频

- 资产详情页不自动播放视频，只展示 poster/缩略图和居中的播放按钮。
- 用户点击播放按钮或视频主体后打开全屏视频预览，并在全屏预览内加载视频播放器。
- 全屏播放器至少支持播放、暂停、进度拖拽、静音/取消静音、播放失败提示和退出全屏；P0 统一使用 MP4 proxy，不在播放器中回退原视频。proxy 不可用时展示错误和重试，不静默拉取大体积原视频。
- 在用户明确点击之前不得请求或启动视频播放，避免资产列表和详情页产生额外带宽与自动播放噪音。

#### 音频

- 用户在资产详情中点击音频资产后开始播放，详情组件展示播放进度条、当前时间和总时长。
- 进度条支持拖拽跳转，提供播放/暂停控制；切换其他资产或关闭详情时停止当前播放并释放资源。
- 音频播放器使用支持 Range 的预览或代理地址，不能为了展示进度而一次性下载完整原文件。

#### 文档

- 文档资产在详情组件中自动加载可阅读内容，并提供全屏阅读按钮。
- Markdown 文档必须渲染为安全的富文本，禁止执行原始 HTML、脚本或不可信链接协议；普通文本至少提供等宽或段落化阅读。
- 文档内容必须经过当前用户/资产权限校验并限制最大返回字节数；Markdown 中的外部图片、iframe、音视频和自定义 HTML 默认移除，链接仅允许 `https`、`http`（是否允许外链由安全策略配置），禁止 `javascript:`、`data:` 等协议，避免 XSS 和隐私泄露。
- 文档内容加载失败时展示明确错误和重试按钮，不影响详情组件其他字段操作。

#### 其他类型

- 当前不支持预览的资产类型展示类型占位、文件名、大小和下载操作，并明确提示“暂不支持预览”。
- 不得尝试将未知类型强行当作图片、视频、音频或文档加载。
- 预览内容需遵循当前用户权限和资产软删除状态；临时访问地址短期有效，过期后自动重新获取，不得把签名地址持久化到浏览器存储。

## 6. 管理后台需求

### 6.1 接入账号

页面一级子 Tab：

```text
图片 | 视频 | 音频 | 文本
```

#### 图片

- 迁移现有图片账号和真实模型配置，不改变数据或业务行为。
- 保留账号筛选、增删改、启停、测试连接和模型管理。

#### 视频

- 使用“账号列表 + 账号下真实模型列表”的主从结构。
- 账号支持 Seedance、MiniMax。
- 一个账号可配置多个真实视频模型。
- 不同账号可配置相同的模型代码。
- 账号表展示名称、供应商、状态、并发、超时、权重和凭据状态。
- 模型表展示模型代码、显示名称、任务类型、能力摘要、能力版本、成本版本和状态。
- 视频能力使用结构化表单维护，保留高级 JSON 编辑器用于未结构化的厂商扩展字段。
- 新增和编辑时使用账号、模型选择器，不要求手工输入数据库 ID。

#### 音频

- 展示统一空状态：“音频模型能力尚未接入”。
- 不出现无法执行的新增按钮。

#### 文本

- 迁移当前文本模型账号和模型配置。
- 保留账号、模型、默认模型、连接测试、输入/输出 Token 成本等现有能力。
- 从系统设置中移除“文本模型”Tab。

### 6.2 路由模型

页面一级子 Tab：

```text
图片 | 视频 | 音频 | 文本
```

#### 视频路由

- 视频路由只展示 `media_type=video` 的路由。
- 支持管理路由名称、代码、描述、可见性、状态和排序。
- 支持为一个路由绑定多个视频账号模型候选。
- 候选表展示账号、真实模型、优先级、权重、回退顺序和状态。
- 支持配置视频任务类型、分辨率、比例、时长、音频模式、首尾帧能力、默认值和最大输出数量。
- 支持绑定视频价格策略。
- 保持现有视频运行时选择语义，不在本期修改权重与失败回退算法。

#### 文本路由

- 本期只提供说明性视图或现有默认文本模型状态，不伪造不存在的通用路由能力。
- 页面必须明确文本当前由默认模型选择机制驱动。

### 6.3 价格策略

页面一级子 Tab：

```text
图片 | 视频 | 音频 | 文本
```

#### 视频价格

- 以列表管理价格策略和价格规则，不再以单个 ID 输入框作为主要操作方式。
- 展示并支持配置：
  - 销售积分；
  - 最低净积分收入；
  - 支付费率；
  - 目标毛利；
  - 供应商成本缓冲；
  - 平台固定成本；
  - 输出秒成本；
  - 参考素材成本；
  - 音频固定和按秒成本；
  - exact/metered reserve markup；
  - 最低计费秒数；
  - 价格安全线。
- 支持价格试算、重新计算、启停和软删除。
- 删除不得破坏历史任务的价格快照。

#### 文本价格

- 本期展示并编辑现有文本模型的输入/输出 Token 成本。
- 不新增通用文本销售价格策略和文本路由计费。

### 6.4 视频任务页面稳定性

- 空数据时展示空状态，不得白屏。
- 后端列表接口必须返回 `items: []`，不能返回 `null`。
- 前端 API 层和页面层均需对异常空值做兼容。
- 详情中的 `items`、每项的 `attempts` 也必须归一化为空数组。
- 已有筛选、刷新和恢复操作保持可用。

### 6.5 菜单名称

- “调用记录”统一改名为“图片任务”。
- 菜单、页头、加载、错误、刷新和空状态文案同步修改。
- 保留路由 ID `call-records` 和 URL `#/call-records`，避免破坏已有链接与权限配置。

### 6.6 媒体策略迁移

- 从主导航移除独立“媒体策略”菜单。
- 在“系统设置”新增“媒体策略”Tab，位于“附件策略”右侧。
- 复用现有媒体策略 API 和配置数据，不迁移数据库。
- 旧地址 `#/media-policy` 自动跳转到 `#/system-settings?tab=media-policy`。
- 媒体策略加入系统设置现有的刷新、脏数据离开确认和保存中切换保护机制。

## 7. 兼容性要求

- 历史图片、历史引用资产、历史视频任务和历史价格快照继续可读。
- 资产项目迁移不得导致现有引用失效。
- 旧管理后台 URL 保持兼容。
- 现有图片模型、图片路由和图片价格数据不做破坏性迁移。
- 文本提示词优化继续使用现有默认文本模型机制。
- `media_upload` 未开启时后端继续拒绝新建上传，前端隐藏入口并展示可理解的状态；开启后应能正常展示入口并创建上传任务。
- 视频预览必须满足用户显式点击后才发起 proxy 访问；浏览器不支持 Fullscreen API 时使用等价覆盖层，不影响播放控制。

## 8. 验收标准

### 8.1 上传与引用

- 在创作页上传一张本地图片，上传完成后图片自动成为编辑来源。
- 切换到同一项目资产页可看到该图片，来源为“本地上传”。
- 对象存储中只有一份原始文件，引用关系不产生副本。
- 在提示词中粘贴图片，上传任务列表展示进度，完成后插入资产 Token。
- 粘贴普通文本仍按原行为执行。
- 一次选择多文件时，所有合法文件均进入任务列表并独立显示状态。
- 管理后台在“系统设置-站点”中开启 `media_upload`、`creative_canvas`、`video_creation` 后，保存请求使用 `/api/ops/admin/v1/config-tabs/site`，且使用接口返回的最新 `site.version`。
- 开关保存成功后，`GET /api/agent/features/v1` 返回对应开关值；资产页上传入口和 `UploadTray` 正常显示，上传初始化接口不再返回 `FEATURE_DISABLED`。
- 错误调用 `/api/ops/admin/v1/config-tabs/features` 应返回明确的 `config tab not found`，管理端不得生成该路径。

### 8.2 预览

- 有缩略图时优先加载缩略图。
- 无缩略图时可以自动展示 preview 或原图。
- 预览请求不得使用 `purpose=download`；服务端 `purpose=preview` 的降级结果可以是原图，但需设置缓存、Range/Content-Length 和合理的 `Content-Type`。
- 刷新资产页后仍会发起必要的访问请求并显示图片。
- 新上传视频在 poster 派生完成后显示静态缩略图；poster 处理失败时显示可重试状态。
- 临时 URL 过期后可以自动恢复。
- 不合法或不可访问资产显示明确占位和错误状态，不造成页面白屏。
- 图片资产详情点击主体可打开全屏查看器，并支持放大、缩小和拖拽平移。
- 视频资产详情不自动播放，点击播放后进入全屏播放器并使用 MP4 proxy。
- 音频资产详情点击后播放，进度条可拖拽且支持暂停。
- 文档资产详情自动加载内容，支持全屏阅读；Markdown 内容正确渲染且无脚本执行。
- 资产详情的全屏、播放器和文档阅读均支持关闭、Esc 退出、焦点回收和基础键盘可操作性；无法调用浏览器全屏 API 时必须有可用的覆盖层降级。
- 其他类型资产展示“暂不支持预览”，仍可查看元数据并下载。

### 8.3 管理后台

- 接入账号、路由模型、价格策略均有图片、视频、音频、文本 Tab。
- 可以创建两个视频账号，并分别在每个账号下创建多个视频模型。
- 视频路由可以从选择器绑定多个账号模型。
- 视频价格策略和规则可以列表化新增、编辑、试算、启停和软删除。
- 文本账号和模型可在接入账号页管理，系统设置不再显示文本模型 Tab。
- 视频任务无数据时显示空状态。
- 菜单显示“图片任务”，旧地址仍能访问。
- 媒体策略位于系统设置附件策略右侧，旧地址能够跳转。

## 9. 发布约束

- 本期涉及共享 API 类型、用户端、管理端、Go 服务和数据库关系，按重量级变更执行。
- 发布前必须完成完整 Go 测试、vet、用户端和管理端 typecheck/build、API smoke、代码评审门禁。
- 若增加 `reference_assets.media_asset_id`，数据库迁移必须兼容历史空值并可幂等回填，不能直接添加不可空约束导致旧库升级失败。
- 外键删除行为必须明确为保留历史引用（建议 `ON DELETE SET NULL` 配合软删除），对象存储清理需在确认无资产、引用、任务快照和派生资源依赖后异步执行。
