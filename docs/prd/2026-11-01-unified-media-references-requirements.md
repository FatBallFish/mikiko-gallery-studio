# 统一媒体资产与引用修复需求

日期：2026-11-01
来源：用户在本次会话明确提出的四项改造及测试发布要求。

## 验收要求

1. 统一媒体资产是图片编辑、视频引用、画布与普通工作台的权威资产数据。用户不需要将媒体 ID 转换为另一套参考图 ID。
2. 启动时自动迁移历史参考图资产，重复启动/升级可幂等运行。保留历史任务、画布、提示词引用与对象存储身份，不重复建档，不误删文件，不跨用户关联。历史 ID 保持兼容。
3. 新上传在统一资产列表可见；普通工作台、画布与 MCP 上传使用统一上传协议。上传返回的统一资产 ID 可直接用于图片编辑及视频引用。
4. 画布与资产列表按同一项目工作；画布抽屉支持服务端筛选、游标分页、上传刷新及处理中状态更新。
5. 处理中、失败、已删除及不适配类型的资产不得被当作可用引用；选择与提交均有准确提示，后端强制校验。
6. 验证历史迁移首次、重复、重启、已有关联及所有权隔离；验证上传到列表、图片编辑和视频引用链路。执行仓库验证、审查、隔离 smoke 后提交推送并打新 tag。

## 发布授权

用户已明确授权完成实现、测试、远端推送及创建版本 tag。具体发布版本使用远端最新应用 SemVer 的下一补丁版本，发布前再次检查避免覆盖。
