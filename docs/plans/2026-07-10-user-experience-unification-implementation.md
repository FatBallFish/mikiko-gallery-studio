# User Experience Unification Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Rebuild the landing page and authenticated user application around one responsive Luminous Vault design system, and add a separately built and deployed API documentation site.

**Architecture:** Establish user design tokens, primitives, motion utilities, and a stable shell before migrating routes. Keep API clients and business contracts unchanged, use GSAP only for coordinated landing-page storytelling, and route all documentation entry points to a new `web/docs` React application whose endpoint reference is synchronized from the repository OpenAPI source.

**Tech Stack:** React 19, TypeScript 5.8, Vite 7, Tailwind CSS 4, Lucide React, GSAP with `@gsap/react`, Scalar OpenAPI Reference, CSS custom properties, repository contract tests, agent-browser/Playwright-compatible browser verification.
