# 引用准入与模型稳定选择修复

日期：2026-10-26。来源：本会话用户五项明确要求；延续未提交代码，不自动commit/push/deploy，不调用真实付费模型。

## 要求

1. 图片创作、视频创作和画布控制台，对不支持的引用类型与超上限引用，在上传/资产选择/连接之前拒绝，Toast明确原因；不能先加入再截断/删除。组合数量及并发上传按当前有效能力校验。已存在的不兼容引用保留并禁用生成，说明如何处理。
2. 用户选定型号不因能力变化、引用变化、估价失败自动换成GPT或其他模型。仅首次无选择时可选默认；失效/下线/无权限/不支持操作保留选择并展示原因，禁止生成。视频与画布同样处理。
3. 图片引用自动生成/编辑按当前引用判定，但不能据此把选择集合替换为另一型号。区分generate/edit/layer profile约束，缺能力/未知不能误判成max0并删引用。
4. 创作参数展开/收起按钮检查真实用途：移动端保持有效；桌面无效果则移除桌面ICON或让动作真实生效，不保留假按钮。
5. Seedream拆层入口说明与可测试状态准确：需要能力profile操作和已确认成本/售价支持，在用户控制台独立可见；条件不满足展示明确原因，不能默默隐藏。开启普通参考编辑仍可导入，不误用拆层数上限；本轮不触发付费拆层实测。

## 设计

复用统一准入helper计算当前选择model+tasktype的能力与剩余引用槽位；不混用文生图maxrefs0与编辑能力。上传含排队中的引用预约、导入批次在添加前校验，拒绝保留原列表且显示原因。资产选择弹窗禁用不支持类型/超额提交，避免先成功Toast再截断。模型归一化仅填空，不覆盖显式选择；失效模型有占位显示和可解释阻断。Canvas连接和上传完成路径用当前目标/引用签名重新校验，支持图/视频/首尾帧等任务专属约束。后端如能力聚合不正确修正投影并补回归，不放宽实际约束。

## 验证

回归无效模型不切换、0/满额/混合批次/并发上传/去重、视频图与视频分别上限、Canvas连接与上传回调、Seedream generate/edit/layer能力。浏览器无付费验证创作图片/视频/画布的禁用原因与Toast、参数toggle和拆层入口。全量verify、独立review；后端改动则隔离API smoke。保留既有所有变更与配置，不读取secret/swap。
