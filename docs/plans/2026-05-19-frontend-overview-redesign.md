## Goal

先产出两个可运行的总览 Demo 页，用于评审整体主题、信息架构与视觉语言，再基于评审结果沉淀为标准并重写全部业务页面。

## Approved Direction

### 1. 用户端：Luminous Vault
- 定位：高奢数字艺廊 + 创作控制台
- 气质：沉浸、华丽、艺术性强，但操作锚点明确
- 视觉：深色多层光场、镜面玻璃、金属描边、丰富但受控的色彩、强标题与稳定正文
- 核心目标：让用户一眼感到“这是一个艺术生成平台”，同时能立刻理解如何开始生图、怎么看结果、怎么继续操作

### 2. 管理后台：Soft Grid Ops
- 定位：极简运维中枢
- 气质：苹果式极简、留白充足、状态清晰、可靠安静
- 视觉：浅灰白基底、低饱和蓝灰点缀、柔和阴影、精确网格、低噪音高反馈
- 核心目标：让管理员快速理解系统健康、配置状态、审核队列与模型策略变更，不被装饰干扰

## Demo Scope

### 用户端总览 Demo
- 品牌区与登录态总览
- 生成工作台预览
- 历史图库预览
- 开发文档与接入能力预览
- 任务反馈与系统状态预览

### 管理后台总览 Demo
- 系统状态与告警总览
- 配置中心 Tab 概览
- 模型路由与价格策略概览
- 审核 / 审计 / 任务监控概览
- 高优先级操作反馈样式预览

## Interaction Standard
- 关键操作必须有状态反馈：处理中、成功、失败、冲突、待确认
- 中后台页面强调信息层次、主次关系与可扫描性
- Demo 先覆盖主题、布局和组件语言，不直接绑定真实业务数据

## Output
- `web/user`: 用户端总览 Demo
- `web/admin`: 管理后台总览 Demo
