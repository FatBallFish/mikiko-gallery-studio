# 视频资产公开与审核修复

## 需求与授权

用户在本会话明确要求：先完成远端部署，再修复资产页视频资产的公开状态、公开按钮和 tips 布局；修复后台审核通过视频返回 INTERNAL_ERROR（request_id a0d55cb4fd31e99e），并复测拒绝审核。验证后重新发布并升级生产。生产恢复已于 v0.0.40 完成，此任务延续用户对提交、推送、打标签和 mgsctl 部署的授权。

## 既有需求设计来源

- docs/plans/2026-10-24-public-media-history-remediation.md 定义视频待审核、公开、拒绝、撤回生命周期以及管理员审核和公开访问边界。
- docs/prd/2026-10-25-native-image-models-and-public-feed.md 要求审核通过图片视频混排。
- docs/tech/2026-10-25-native-image-models-and-public-feed.md 要求公共投影遵守审核权限。

## 修复与验证设计

先从当前组件 DOM/CSS 与服务端日志、数据库约束查明根因。公开区布局应隔离图片视频样式冲突，保持状态、按钮、说明清晰可读，窄屏允许合理换行，不改变公开权限。审核状态更新沿用原有管理员授权、事务和审计，修复视频与图片实体投影差异，不直接修改生产数据库记录。回归覆盖视频审核通过、拒绝及拒绝原因，验证公开列表与匿名访问仅允许已通过资产，并保持图片审核行为。

使用聚焦回归、前后端类型构建、完整 verify、独立复核和隔离 API smoke；浏览器验收公开区域主要状态和手机/桌面。完成正式 release 后使用 mgsctl 升级并核对版本、健康及审核功能。生产审核若涉及现有用户内容，不为测试改变其公开状态；优先使用隔离 fixture 或本轮授权测试资产。
